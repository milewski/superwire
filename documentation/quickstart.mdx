title: Quickstart
description: Build and run a small Engine AI workflow with the current Rust runtime.
---

This quickstart uses the default runtime with Ollama because it is the lowest-friction way to run a real workflow locally.

## 1. Start a model provider

Install and start Ollama, then pull a model:

```bash
ollama pull qwen3.5:8b
```

## 2. Create a workflow

Save this as `hello.ai`:

```txt
provider ollama {
    driver: "ollama"
    models: ["qwen3.5:8b"]
}

agent greeting {
    model: ollama("qwen3.5:8b")
    prompt: "Write a one-sentence welcome message for a new user."
    output: string
}

output {
    greeting: agent.greeting
}
```

## 3. Execute it from Rust

```rust
use engine_ai_core::runtime::try_workflow_from_source;
use serde::Deserialize;

#[derive(Debug, Deserialize)]
struct Output {
    greeting: String,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let workflow_source = include_str!("../hello.ai");
    let workflow_result: Result<Output, _> = try_workflow_from_source(workflow_source).await?;
    let workflow_output = workflow_result?;

    println!("{}", workflow_output.greeting);

    Ok(())
}
```

## 4. Add input values

Typed input makes workflows reusable:

```txt
provider ollama {
    driver: "ollama"
    models: ["qwen3.5:8b"]
}

input {
    topic: string
    audience: string
}

agent summary {
    model: ollama("qwen3.5:8b")
    prompt: "Explain {{ input.topic }} for {{ input.audience }}."
    output: {
        title: string
        summary: string
    }
}

output {
    title: agent.summary.title
    summary: agent.summary.summary
}
```

```rust
use engine_ai_core::runtime::try_workflow_from_source_with_values;
use serde::Deserialize;
use serde_json::json;

#[derive(Debug, Deserialize)]
struct Output {
    title: String,
    summary: String,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let workflow_source = include_str!("../summary.ai");
    let input_values = json!({
        "topic": "agent workflows",
        "audience": "Rust developers"
    });

    let workflow_result: Result<Output, _> =
        try_workflow_from_source_with_values(workflow_source, input_values, json!({})).await?;
    let workflow_output = workflow_result?;

    println!("{:?}", workflow_output);

    Ok(())
}
```

<Tip>
  If you want deterministic tests without a live model, use
  `WorkflowRuntime::new(ScriptedProviderFactory::new(...))`. The testing guide
  shows the full pattern.
</Tip>

## 5. Know the current runtime boundary

The default runtime currently executes standard agents that use `model`, `prompt`, and optional `output` validation.

<Warning>
  Syntax such as agent `for` loops, `context(...)`, `compact(...)`,
  `template(...)`, and `tool.*` references is parsed and documented, but the
  default runtime does not execute those features yet.
</Warning>
