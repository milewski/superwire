---
title: Quickstart
description: Build and run a small Engine AI workflow with the current Rust runtime.
---

This quickstart uses the default runtime with Ollama because it is the lowest-friction way to run a real workflow locally.

## 1. Start a model provider

Install and start Ollama, then pull a model:

```bash
ollama pull qwen3.5:8b
```

## 2. Create a workflow

Save this as `hello.ai`:

```ai-dsl
provider ollama {
    driver: "ollama"
    endpoint: "http://localhost:11434"
    models: ["qwen3.5:8b"]
}

agent greeting {
    model: ollama("qwen3.5:8b")
    prompt: "Write a one-sentence welcome message for a new user."
    output: string
}

output {
    greeting: agent.greeting
}
```

## 3. Execute it from Rust

```rust
use engine_ai_core::dsl::parse_workflow;
use engine_ai_core::runtime::execute_workflow_without_input;
use schemars::JsonSchema;
use serde::Deserialize;

#[derive(Debug, Deserialize, JsonSchema)]
struct Output {
    greeting: String,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let workflow_source = include_str!("../hello.ai");
    let workflow = parse_workflow(workflow_source)?;
    let workflow_output: Output = execute_workflow_without_input(&workflow).await?;

    println!("{}", workflow_output.greeting);

    Ok(())
}
```

## 4. Add input values

Typed input makes workflows reusable:

```ai-dsl
provider ollama {
    driver: "ollama"
    endpoint: "http://localhost:11434"
    models: ["qwen3.5:8b"]
}

input {
    topic: string
    audience: string
}

agent summary {
    model: ollama("qwen3.5:8b")
    prompt: "Explain {{ input.topic }} for {{ input.audience }}."
    output: {
        title: string
        summary: string
    }
}

output {
    title: agent.summary.title
    summary: agent.summary.summary
}
```

```rust
use engine_ai_core::dsl::parse_workflow;
use engine_ai_core::runtime::execute_workflow;
use schemars::JsonSchema;
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, JsonSchema)]
struct Input {
    topic: String,
    audience: String,
}

#[derive(Debug, Deserialize, JsonSchema)]
struct Output {
    title: String,
    summary: String,
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let workflow_source = include_str!("../summary.ai");
    let workflow = parse_workflow(workflow_source)?;

    let workflow_output: Output = execute_workflow(
        &workflow,
        Input {
            topic: "agent workflows".to_string(),
            audience: "Rust developers".to_string(),
        },
    )
    .await?;

    println!("{:?}", workflow_output);

    Ok(())
}
```

<Tip>
  If you want deterministic tests without a live model, use
  `WorkflowRuntime::run_with_runner(...)` with a custom `AgentRunner`. The testing guide
  shows the full pattern.
</Tip>

## 5. Know the current runtime boundary

The default runtime executes `model`, `prompt`, `output`, `context`, `inference`, and `for` loop agents.

<Warning>
  `tools` and `tool.*` references are still not executed by the runtime and
  return `UnsupportedFeature` when reached.
</Warning>
