---
title: Quickstart
description: Start the executor, write a workflow, and call /execute or /execute/stream.
---

This guide gets a `.wire` file running through the Docker executor service.

## 1. Start the executor

```bash
docker run --rm -p 8080:8080 rmilewski/superwire-executor
```

The service exposes two execution endpoints:

| Endpoint | Response style | Use when |
| --- | --- | --- |
| `POST /execute` | one JSON response | backend jobs, tests, synchronous API calls |
| `POST /execute/stream` | Server-Sent Events | chat UIs, progress displays, long workflows |

Both endpoints receive the same JSON payload.

## 2. Create `hello.wire`

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

input {
    name: string
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

agent greeting {
    model: ai("flash")
    instruction: "Greet {{ input.name }} in one friendly sentence."
    output: {
        message: string
    }
}

output {
    message: agent.greeting.message
}
```

## 3. Encode the workflow

Linux:

```bash
WORKFLOW_SOURCE_BASE64=$(base64 -w0 hello.wire)
```

macOS:

```bash
WORKFLOW_SOURCE_BASE64=$(base64 < hello.wire | tr -d '\n')
```

## 4. Execute the workflow

```bash
curl -s http://localhost:8080/execute \
  -H 'Content-Type: application/json' \
  -d @- <<JSON
{
  "input": {
    "name": "Rafael"
  },
  "secrets": {
    "endpoint": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "YOUR_API_KEY",
    "models": {
      "flash": "qwen3.6-plus",
      "pro": "qwen3.6-plus",
      "max": "qwen3.6-plus"
    }
  },
  "workflow_source_base64": "$WORKFLOW_SOURCE_BASE64"
}
JSON
```

Expected response shape:

```json
{
  "message": "Hello Rafael — welcome!"
}
```

## 5. Stream the same workflow

```bash
curl -N http://localhost:8080/execute/stream \
  -H 'Content-Type: application/json' \
  -d @- <<JSON
{
  "input": {
    "name": "Rafael"
  },
  "secrets": {
    "endpoint": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "api_key": "YOUR_API_KEY",
    "models": {
      "flash": "qwen3.6-plus",
      "pro": "qwen3.6-plus",
      "max": "qwen3.6-plus"
    }
  },
  "workflow_source_base64": "$WORKFLOW_SOURCE_BASE64"
}
JSON
```

The streaming endpoint emits progress and output events as the workflow runs. Event names are documented in [Executor API](/api-reference/executor-api).

## 6. Add structure

Agent outputs are structured. Add more fields when the caller needs machine-readable data:

```wire
agent classify_request {
    model: ai("flash")
    instruction: "Classify this request: {{ input.name }}"
    output: {
        label: enum { bug, feature, question }
        confidence: number
    }
}
```
