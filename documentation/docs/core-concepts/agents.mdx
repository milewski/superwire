title: Agents
description: Define model steps, local dynamic values, capabilities, files, loops, context, and typed output.
---

An agent is one model-backed node in the workflow graph.

```wire
agent summarize {
    model: model.fast
    instruction: "Summarize {{ input.topic }}."

    output {
        summary: string
    }
}
```

## Properties and directives

| Syntax | Purpose |
| --- | --- |
| `model:` | Select a named model profile and optional inference override. |
| `dynamic {}` | Compute values scoped to this agent execution. |
| `uses:` | Expose selected tools, prompts, and resources to the model. |
| `context:` | Continue or compact another agent's message history. |
| `instruction:` | Required instruction expression for the model step. |
| `file <expression>` | Render and upload a temporary file attachment. |
| `output {}` | Required object-shaped model output contract. |

## Agent-local dynamic values

```wire
agent writer {
    model: model.fast

    dynamic {
        prefix: "Write for maintainers"
        request: input.message
    }

    instruction: "{{ dynamic.prefix }}: {{ dynamic.request }}"

    output {
        message: string
    }
}
```

Agent-local fields share the `dynamic` namespace with global dynamic fields, but are evaluated in the agent's local loop/tool scope. Later agents cannot treat a local dynamic field as a global workflow output; return needed values through the agent `output`.

## Object-shaped output and schema reuse

An agent output is always an object block. Reuse a schema as a field type:

```wire
schema classification {
    category: enum { bug, feature, question }
    confidence: number
}

agent classify {
    model: model.fast
    instruction: "Classify {{ input.message }}."

    output {
        result: schema.classification
    }
}
```

Read `agent.classify.result`. A scalar `output: string` or direct `output: schema.classification` is not current agent syntax.

## Scoped capabilities

```wire
agent researcher {
    model: model.fast
    uses: [
        resource.project_readme,
        prompt.research_rules,
        tool.search {
            max_calls: 3
        },
    ]
    instruction: "Research {{ input.topic }}."

    output {
        findings: [string]
    }
}
```

Only listed capabilities are exposed. `max_calls` further bounds a model-owned tool within this agent.

## Context continuation and compaction

Continue full history:

```wire
context: agent.research
```

Compact it through another model step before continuation:

```wire
context: compact agent.research {
    instruction: "Keep decisions, evidence, and unresolved questions."
    model: model.compactor
}
```

The compaction block accepts optional `instruction` and `model`; omitted values use runtime defaults. See [Context continuation](/advanced/context-sharing).

## File attachment

```wire
file agent.draft {
    name: "draft.json"
    purpose: "file-extract"
}
```

The content expression is required; the option block is optional. Defaults are `file.txt` and `file-extract`. String, number, object, array, and reference results are rendered to file content. Multiple directives are allowed.

<Warning>
  The selected model must use `wire_api: "chat/completion"`; Responses mode is rejected for agent files.
</Warning>

## Loops

```wire
agent analyze for { id, title } in input.tasks {
    model: model.fast
    instruction: "Analyze {{ id }}: {{ title }}."

    output {
        task_id: number
        summary: string
    }
}
```

The final `agent.analyze` value is an array of output objects. Iterations may run concurrently up to the execution limit and are returned in input order.
