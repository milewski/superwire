## Provider declarations

Providers accept only `endpoint` and `api_key` properties:

```wire
secrets {
    api_key: string
}

provider primary from anthropic {
    endpoint: "https://api.anthropic.com"
    api_key: secrets.api_key
}
```

Both properties are optional for drivers with defaults. The runtime can use a default endpoint and driver-specific environment key. See the source-backed [Provider matrix](/integrations/providers) for all 17 drivers.

Inference settings do not belong in a provider block.

## Model profiles

```wire
model fast from primary {
    id: "model-id"
    wire_api: "responses"
    assets: ["image"]

    inference {
        temperature: 0.2
        max_tokens: 4_000
        provider_max_retries: 2
        provider_retry_base_delay_ms: 250
    }
}
```

| Property | Meaning |
| --- | --- |
| `id` | Required provider-specific model identifier. |
| `wire_api` | `"responses"` by default or `"chat/completion"`. |
| `assets` | Allowed non-text kinds: `image`, `video`, `document`. |
| `inference` | Defaults for every agent using the profile. |

Supported inference keys are `max_tokens`, `temperature`, `top_p`, `top_k`, `frequency_penalty`, `presence_penalty`, `repeat_penalty`, `seed`, `stuck_threshold`, `provider_max_retries`, and `provider_retry_base_delay_ms`.

## Per-agent override

```wire
agent creative_reply {
    model: model.fast {
        inference {
            temperature: 0.8
        }
    }
    instruction: "Write a creative reply."

    output {
        message: string
    }
}
```

Agent model-usage inference overrides matching profile fields and inherits the rest. It does not create another named model.

## API-mode requirement for files

```wire
model files from primary {
    id: "file-capable-model"
    wire_api: "chat/completion"
}
```

Agent `file` directives require Chat Completions mode. Other model calls default to Responses mode. The backend must implement the chosen API; an “OpenAI-compatible” label does not guarantee every endpoint or feature.
