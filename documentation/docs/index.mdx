# Build a typed AI workflow

Superwire turns server-side AI orchestration into a reviewable `.wire` contract: typed runtime data, explicit dependencies, scoped tools, and structured output.

## What runs where

```text
.wire source + input + secrets
             |
             v
     Superwire executor
       |      |      |
      JSON   SSE   Playground/LSP
```

The executor validates the workflow and runtime values before model execution. Model output can still vary; Superwire makes the graph, tool scopes, type contracts, and final output shape explicit.
