## Start with one contract

One provider, model, agent, and final output is enough for the first working version. Add another node only when it has a distinct input/output responsibility.

## Keep secrets outside source and instructions

Supply provider/MCP credentials through runtime secrets or executor environment variables. Do not interpolate credentials into instructions. Avoid command-line secret JSON when a restricted file or application client is available.

## Prefer structured output

<ClassifyWorkflow />

Typed objects are easier to validate, reference, cache, map into application classes, and evolve than free-form text that another layer must parse.

## Make concurrency visible

<ParallelWorkflow />

Independent references expose safe concurrency. Set an explicit `max_concurrency` in production based on provider/tool capacity; do not assume more parallelism is always faster or cheaper.

## Separate tool ownership

<McpTaskWorkflow />

- Use deterministic `call tool.name` for required operations.
- Use agent `uses` when model judgment is required.
- Put trusted IDs/tenant scope in `bindings`, not model-visible `input`.
- Bound model-owned calls with `max_calls`.
- Keep authorization and transaction safety inside domain tools.

## Continue context only when needed

Use structured references for values. Use full context only for conversational history. Use `compact` when history is large and state what the compactor must preserve.

## Choose API mode deliberately

Models default to `wire_api: "responses"`. Select `"chat/completion"` when the backend requires it and for every agent using a `file` directive.

## Treat cache keys as behavior

A cache key scopes reusable agent results. Include tenant/conversation/version dimensions needed to prevent accidental cross-context reuse. Rotate for a fresh scope and invalidate when deletion is required.

## Validate every source of truth

- Keep complete docs examples in imported checked fixtures.
- Run `superwire-cli workflow check` and `fmt` locally.
- Generate/review `superwire.lock` when MCP schemas matter.
- Exercise JSON and SSE output contracts in the integrating application.
