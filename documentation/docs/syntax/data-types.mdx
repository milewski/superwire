---
title: Data Types
description: Primitive, object, array, tuple, enum, union, variant, and schema reference types.
---

Superwire types describe `input`, `secrets`, schema fields, tool contracts, and agent outputs.

## Primitives

```wire
string
number
float
boolean
null
```

`object` is also available as a broad object type when you do not want to define fixed fields.

```wire
object
```

## Objects

```wire
{
    title: string
    score: number
}
```

Inline object fields use commas:

```wire
{ title: string, score: number }
```

## Arrays

```wire
[string]
[number]
[schema.participant]
```

Fixed-length arrays use a semicolon:

```wire
[string; 3]
```

## Tuples

```wire
(string, number)
(string, number, [string; 3])
```

## Unions and nullable types

Use `|` when a value may be one of multiple types:

```wire
string | number
schema.contact.email | schema.contact.phone
```

Ordinary unions lower to JSON Schema `anyOf`. They do not use `oneOf`, because overlapping member schemas are valid. Use a `variant` when the contract needs an explicit discriminator and named cases.

Use `maybe` as nullable shorthand:

```wire
maybe string
```

`maybe string` is equivalent to `string | null`.

## Enums

Inline enum variants use commas:

```wire
enum { draft, ready, published }
```

Multiline enum variants do not require commas:

```wire
enum {
    draft
    ready
    published
}
```

An enum must contain at least one case. `enum {}` is a parse error with help to add an identifier.

## Schema references

```wire
schema participant {
    name: string
    role: string
}

schema article {
    title: string
    author: schema.participant
}
```

## Variants

Use `variant` for tagged unions where each case has its own object shape.

```wire
schema event_payload {
    payload: variant type {
        user_created {
            user_id: string
        }

        "user.deleted" {
            user_id: string
            reason: maybe string
        }
    }
}
```

You can also define a root-level variant directly on a schema:

```wire
schema api_event {
    variant type {
        created {
            id: string
        }

        deleted {
            id: string
        }
    }
}

```

A variant must contain at least one named case with an object body. `variant type {}` is a targeted parse error.
