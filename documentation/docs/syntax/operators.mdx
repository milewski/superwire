## Access operators

| Syntax | Result |
| --- | --- |
| `input.project_id` | Read an object/reference field. |
| `items.*.field` | Pluck field, preserving null slots. |
| `items.**.field` | Pluck field and drop null slots. |
| `items.***.field` | Pluck field, requiring non-null values of one runtime type. |
| `value ?? fallback` | Replace null with a compatible fallback. |
| `variant#case` | Project the complete case object, including its discriminator, or return null. |
| `variant#case.field` | Project one field from the selected case or return null. |

```wire
output {
    labels: input.items.**.label
    owner: input.owner ?? "unassigned"
    escalation: agent.route.value#escalation.reason ?? "none"
}
```

A mismatched case or nullable source produces null. See the checked whole-case and nullable example in [Control flow](/syntax/control-flow#tagged-variants-match-and-projection).

## Model usage

```wire
model: model.fast
```

Override inference for one agent:

```wire
model: model.fast {
    inference {
        temperature: 0.2
    }
}
```

## Tool and MCP special forms

```wire
call tool.fetch_task {
    input {
        search: "open"
    }

    bindings {
        workspace_id: input.workspace_id
    }

    max_calls: 1
}
```

```wire
read resource.project_readme
render prompt.writer_instructions
```

`input` is model/caller-visible tool input. `bindings` are workflow-owned trusted values. Fixed declaration bindings are merged with call-time bindings, with local values overriding matching shared fields.

## Context special forms

```wire
context agent.research
compact agent.research {
    instruction: "Keep only decisions and evidence."
}
```

In an agent property, include the property name:

```wire
context: compact agent.research {
    instruction: "Keep only decisions and evidence."
}
```

## Inline separators

Use commas for inline arrays, tuples, object types/literals, and enums:

```wire
["a", "b", "c"]
(string, number)
{ title: string, score: number }
enum { draft, ready, published }
```

Multiline fields and enum variants do not require commas. A trailing comma is accepted where the grammar allows an inline list.
