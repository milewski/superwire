---
title: Type annotations
description: Write typed fields for runtime values, schemas, tools, and object-shaped agent output.
---

## Runtime fields

```wire
input {
    project_id: number
    title: string
    urgent: boolean
}

secrets {
    api_key: string
}
```

A field is `name: type`. Runtime JSON must match every required field and nested shape.

## Schema descriptions

```wire
schema task_summary {
    /// Short display title
    title: string

    /// One-paragraph summary
    summary: string

    /// Routing priority
    priority: enum { low, medium, high }
}
```

Triple-slash descriptions are preserved for schema-aware tooling/model output. Regular `//` comments are not field descriptions.

## Agent output

Agent output is a required object block:

```wire
agent summarize {
    model: model.fast
    instruction: "Summarize {{ input.title }}."

    output {
        summary: string
        action_items: [string]
    }
}
```

Reuse a schema as a field type, then reference that field:

```wire
schema summary_output {
    summary: string
    action_items: [string]
}

agent summarize {
    model: model.fast
    instruction: "Summarize {{ input.title }}."

    output {
        result: schema.summary_output
    }
}

output {
    summary: agent.summarize.result.summary
}
```

Direct scalar/schema syntax such as `output: string` or `output: schema.summary_output` is not current agent syntax.

## Tool input, bindings, and output

```wire
tool update_task from mcp.tasks.tool.update_task {
    input {
        status: string
    }

    bindings {
        task_id: input.task_id
    }

    output {
        updated: boolean
    }
}
```

Tool `input` defines model-visible/call-supplied fields. `bindings` contains workflow-owned values. Tool `output` constrains the returned value.
