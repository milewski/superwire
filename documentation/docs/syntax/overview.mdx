## Declarations

| Declaration | Purpose |
| --- | --- |
| `input` | Typed public runtime values. |
| `secrets` | Typed sensitive runtime values. |
| `provider name from driver` | Provider driver, endpoint, and API key. |
| `model name from provider` | Model ID, API mode, assets, inference defaults. |
| `schema name` | Reusable object or tagged-variant type. |
| `mcp name` | MCP endpoint and headers. |
| `tool`, `resource`, `prompt` | MCP capability imports. |
| `from mcp...` | Batch capability import. |
| `dynamic` | Runtime-computed object fields. |
| `agent` | Model step, optionally looped. |
| `output` | Final application-shaped value. |

## Reference roots

Runtime/value roots:

```wire
input.project_id
secrets.api_key
agent.research.findings
dynamic.task
tool.fetch_task
resource.project_readme
prompt.writer_rules
```

`model.fast` appears in model usage. `schema.task` appears in type positions.

## Naming and formatting

Use descriptive lowercase snake_case names. Format with:

```bash
superwire-cli fmt workflow.wire
```
