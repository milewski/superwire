The agent output remains object-shaped: it has a `result` field whose type is `schema.classification`. Later expressions read `agent.classify.result`.

Example final object:

```json
{
  "result": {
    "category": "feature",
    "confidence": 0.91,
    "reason": "The request asks for new behavior."
  }
}
```

Enums constrain category names; `number` constrains confidence to a numeric JSON value. Output validation happens after the model response and before downstream references consume it.
