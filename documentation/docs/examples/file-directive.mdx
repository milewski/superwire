<Warning>
  Agent files require the selected model to declare `wire_api: "chat/completion"`. The default `"responses"` mode fails validation for `file` directives.
</Warning>

The draft agent returns an object. The review agent renders that object as `report.json`, uploads it before the model call, and removes the provider file during cleanup.

Streaming clients can observe `agent_file_created` and `agent_file_deleted`. Provider failures can still occur if the backend does not implement compatible file upload and deletion endpoints.
