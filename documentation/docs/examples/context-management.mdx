`context: agent.investigate` passes prior message history into `solve`; it does not read a structured field. A structured reference such as `agent.investigate.problem` reads only the declared output value.

| Need | Use |
| --- | --- |
| One typed value | `agent.investigate.problem` |
| Prior conversation history | `context: agent.investigate` |
| Shortened prior history | `context: compact agent.investigate { ... }` |

See [Context continuation and compaction](/advanced/context-sharing).
