The final `output` block can compose runtime input and a complete agent object. HTTP JSON adds only the transport wrapper:

```json
{
  "output": {
    "project": {
      "id": 42,
      "topic": "Release readiness",
      "plan": {
        "summary": "...",
        "tasks": [
          {"title": "Verify rollout", "priority": "high"}
        ]
      }
    }
  }
}
```

The model supplies `plan`; the runtime supplies `id` and `topic` directly from typed input.
