`agent.summarize` references `agent.research.facts`, so the execution graph waits for research before summary. The final object deliberately returns both the intermediate facts and the derived summary.

```text
research -> summarize -> output
```

Use structured references when a later step needs values. Use [context continuation](/examples/context-management) only when it needs the earlier conversation history.
