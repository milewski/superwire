---
title: Context continuation and compaction
description: Pass full agent history or compact it before a later step.
---

## Continue full history

```wire
agent investigate {
    model: model.fast
    instruction: "Investigate {{ input.topic }}."

    output {
        findings: [string]
    }
}

agent decide {
    model: model.fast
    context: agent.investigate
    instruction: "Continue the investigation and make a decision."

    output {
        decision: string
    }
}
```

`context` passes the earlier agent's message history. It is different from reading `agent.investigate.findings`, which passes one typed output value through instruction interpolation.

## Compact first

```wire
agent decide {
    model: model.fast
    context: compact agent.investigate {
        model: model.compactor
        instruction: "Keep decisions, evidence, and unresolved questions."
    }
    instruction: "Use the compacted history to make a decision."

    output {
        decision: string
    }
}
```

The optional block selects the compaction model and instruction. Compaction is a model call, not lossless compression; its content can vary and consumes provider capacity.

## Events

Streaming exposes:

- `context_compaction_started`;
- `context_compaction_completed` with timing/context data;
- `context_compaction_failed` with a message.

## Guidance

- Prefer structured references when the next step needs only declared values.
- Continue full context when conversational reasoning/history matters.
- Compact when full history is too large or contains irrelevant detail.
- State what compaction must preserve; do not assume it retains every fact.
- Avoid placing secrets in instructions/history because context is sent to the provider.
