Superwire is unreleased, so this page describes the current authoring conventions directly.

## Current conventions

- Use `instruction:` for the model instruction text.
- Use `uses:` for agent tool access.
- Use object-shaped agent outputs.
- Use lowercase snake_case schema names.
- Use `bindings` for workflow-supplied tool values.
- Use `_` as the catch-all branch in `match` expressions.

## Minimal agent

```wire
agent summarize {
    model: ai("flash")
    instruction: "Summarize {{ input.topic }}."
    output: {
        summary: string
    }
}
```
