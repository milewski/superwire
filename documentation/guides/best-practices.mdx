---
title: Best Practices
description: Patterns that keep workflows readable, safe, and easy to evolve.
---

## Keep secrets out of instructions

```wire
secrets {
    api_key: string
}
```

Do not interpolate secrets into model instructions unless the external provider explicitly needs that value.

## Use model aliases

```wire
agent fast_draft {
    model: ai("flash")
    instruction: "Draft quickly."
    output: {
        draft: string
    }
}

agent final_review {
    model: ai("pro")
    instruction: "Review: {{ agent.fast_draft.draft }}"
    output: {
        approved: boolean
        notes: [string]
    }
}
```

Aliases let you switch concrete models through `secrets.models` without editing workflow logic.

## Prefer structured outputs

```wire
output: {
    answer: string
    confidence: number
    citations: [string]
}
```

Avoid one large text field when the caller needs routing, confidence, status, or IDs.

## Keep agents focused

Use multiple small agents instead of one broad agent when the workflow has separable stages.

## Use schemas for shared fields

```wire
schema shared {
    status: enum { draft, ready, published }
}

schema article {
    title: string
    status: schema.shared.status
}
```

## Prefer dynamic blocks for deterministic tool calls

When the workflow always needs a tool result, call it in `dynamic` instead of asking the model to decide.

```wire
dynamic {
    task: call tool.fetch_task {
        input {
            task_id: input.task_id
        }
    }
}
```
