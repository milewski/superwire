## Code Organization

### Clear Structure

Organize workflows with clear sections:

```rust
// ============================================
// CONFIGURATION
// ============================================

provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

// ============================================
// INPUT VARIABLES
// ============================================

input_data <- "data to process"

// ============================================
// PROCESSING
// ============================================

<- agent processor {
    model <- "ollama/qwen3:8b"
    prompt <- "Process: {{ input_data }}"
}
```

### Descriptive Names

Use clear, descriptive names:

```rust
// Good
<- agent sentiment_analyzer {
    model <- "ollama/qwen3:8b"
    prompt <- "Analyze sentiment"
}

// Avoid
<- agent a {
    model <- "ollama/qwen3:8b"
    prompt <- "Analyze sentiment"
}
```

## Performance

### Maximize Parallelization

Run independent agents in parallel:

```rust
// Good: Parallel execution
<- agent task1 {
    model <- "ollama/qwen3:8b"
    prompt <- "Task 1"
}

<- agent task2 {
    model <- "ollama/qwen3:8b"
    prompt <- "Task 2"
}

// Avoid: Unnecessary sequential execution
<- agent task1 {
    model <- "ollama/qwen3:8b"
    prompt <- "Task 1"
}

<- agent task2 {
    model <- "ollama/qwen3:8b"
    prompt <- "Task 2 using {{ task1.text }}"  // Creates dependency
}
```

### Choose Appropriate Models

Use the right model for each task:

```rust
// Fast local model for simple tasks
agent simple_task {
    model <- "ollama/qwen3:8b"
    prompt <- "Simple classification"
}

// Powerful cloud model for complex tasks
agent complex_task {
    model <- "openai/gpt-4"
    prompt <- "Complex reasoning"
}
```

## Reliability

### Error Handling

Always include fallback paths:

```rust
<- agent primary {
    model <- "ollama/qwen3:8b"
    prompt <- "Primary approach"
}

agent fallback {
    model <- "ollama/qwen3:8b"
    prompt <- "Fallback approach"
    when <- primary.text == null
}
```

### Validation

Validate outputs before proceeding:

```rust
<- agent generator {
    model <- "ollama/qwen3:8b"
    prompt <- "Generate data"
}

<- agent validator {
    model <- "ollama/qwen3:8b"
    prompt <- "Validate: {{ generator.text }}"
}

agent processor {
    model <- "ollama/qwen3:8b"
    prompt <- "Process: {{ generator.text }}"
    when <- validator.text == "valid"
}
```

## Security

### API Keys

Never hardcode API keys:

```rust
// Avoid: Hardcoded key
provider openai {
    driver <- "openai"
    config <- {
        api_key <- "sk-proj-abc123..."  // Don't do this!
        endpoint <- "https://api.openai.com/v1"
    }
    models <- ["gpt-4"]
}

// Good: Use secure configuration
provider openai {
    driver <- "openai"
    config <- {
        api_key <- "sk-proj-..."  // Placeholder only
        endpoint <- "https://api.openai.com/v1"
    }
    models <- ["gpt-4"]
}
```

### Input Validation

Validate user inputs:

```rust
user_input <- "untrusted input"

<- agent validator {
    model <- "ollama/qwen3:8b"
    prompt <- "Validate this input is safe: {{ user_input }}"
}

agent processor {
    model <- "ollama/qwen3:8b"
    prompt <- "Process: {{ user_input }}"
    when <- validator.text == "safe"
}
```

## Maintainability

### Comments

Document complex logic:

```rust
// Multi-stage content pipeline
// 1. Generate initial draft
// 2. Review for quality
// 3. Format for publication

<- agent drafter {
    model <- "ollama/qwen3:8b"
    prompt <- "Create draft"
}

<- agent reviewer {
    model <- "ollama/qwen3:8b"
    prompt <- "Review: {{ drafter.text }}"
}

<- agent formatter {
    model <- "ollama/qwen3:8b"
    prompt <- "Format: {{ reviewer.text }}"
}
```

### Modularity

Break complex workflows into smaller pieces:

```rust
// Reusable validation component
<- agent validate_input {
    model <- "ollama/qwen3:8b"
    prompt <- "Validate input"
}

// Reusable processing component
agent process_data {
    model <- "ollama/qwen3:8b"
    prompt <- "Process data"
    when <- validate_input.text == "valid"
}
```
