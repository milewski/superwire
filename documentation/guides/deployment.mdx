## Deployment Options

### Standalone Binary

Deploy the CLI as a standalone binary:

```bash
# Build release binary
cargo build --release

# Copy to deployment location
cp target/release/engine-ai /usr/local/bin/

# Run workflow
engine-ai run workflow.ai
```

### Docker Container

Create a Dockerfile:

```dockerfile
FROM rust:1.70 as builder
WORKDIR /app
COPY . .
RUN cargo build --release

FROM debian:bookworm-slim
COPY --from=builder /app/target/release/engine-ai /usr/local/bin/
COPY workflows /workflows
CMD ["engine-ai", "run", "/workflows/main.ai"]
```

Build and run:

```bash
docker build -t engine-ai-app .
docker run engine-ai-app
```

### Kubernetes

Deploy with Kubernetes:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: engine-ai
spec:
  replicas: 3
  selector:
    matchLabels:
      app: engine-ai
  template:
    metadata:
      labels:
        app: engine-ai
    spec:
      containers:
      - name: engine-ai
        image: engine-ai-app:latest
        command: ["engine-ai", "run", "/workflows/main.ai"]
```

### Serverless

Deploy as serverless function:

```javascript
// AWS Lambda handler
const { Engine } = require('engine-ai');

exports.handler = async (event) => {
  const engine = new Engine();
  const result = await engine.executeWorkflowString(event.workflow);
  return {
    statusCode: 200,
    body: JSON.stringify(result)
  };
};
```

## Configuration Management

### Environment-Specific Config

```ai
// production.ai
provider openai {
    driver <- "openai"
    config <- {
        api_key <- "sk-proj-..."
        endpoint <- "https://api.openai.com/v1"
    }
    models <- ["gpt-4"]
}
```

```ai
// development.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}
```

### Secrets Management

Never hardcode secrets:

```bash
# Use environment variables
export OPENAI_API_KEY="sk-proj-..."

# Or use secrets manager
aws secretsmanager get-secret-value --secret-id openai-key
```

## Monitoring

### Logging

Enable verbose logging:

```bash
ENGINE_AI_LOG=debug engine-ai run workflow.ai
```

### Metrics

Track workflow execution:

```bash
# Time execution
time engine-ai run workflow.ai

# Monitor resource usage
top -p $(pgrep engine-ai)
```

## Best Practices

<Tip>
  Use local providers for development, cloud providers for production.
</Tip>

<Warning>
  Never commit API keys or secrets to version control.
</Warning>

<Info>
  Test thoroughly in staging before deploying to production.
</Info>
