---
title: Testing Workflows
description: Parse, validate, and execute workflows in Rust tests with deterministic providers.
---

The Rust API supports three useful testing layers.

## Parse-only tests

Use parse tests when you want fast syntax coverage.

```rust
use superwire_core::dsl::parse_workflow;

#[test]
fn workflow_parses() {
    let workflow_source = include_str!("../../crates/core/workflows/minimum.wire");
    let workflow = parse_workflow(workflow_source).expect("workflow should parse");

    assert!(!workflow.declarations().is_empty());
}
```

## Validation tests

Use validation tests when you want to check names, references, or secret-safety rules without calling a provider.

```rust
use superwire_core::dsl::{parse_workflow, validate_workflow};

#[test]
fn workflow_validates() {
    let workflow_source = include_str!("../../crates/core/workflows/minimum.wire");
    let workflow = parse_workflow(workflow_source).expect("workflow should parse");
    let report = validate_workflow(&workflow);

    assert!(report.is_valid(), "{report:?}");
}
```

## Runtime tests with scripted outputs

The most practical execution test pattern uses a custom `AgentRunner` so you can assert output wiring without a live model.

```rust
use async_trait::async_trait;
use superwire_core::parse_inline_workflow;
use superwire_core::runtime::{AgentExecutionRequest, AgentExecutionResult, AgentRunner, WorkflowRuntime, WorkflowRuntimeError};
use schemars::JsonSchema;
use serde::Deserialize;
use serde_json::json;

struct ScriptedRunner;

#[async_trait]
impl AgentRunner for ScriptedRunner {
    async fn run_agent(&self, request: &AgentExecutionRequest) -> Result<AgentExecutionResult, WorkflowRuntimeError> {
        Ok(AgentExecutionResult {
            output: json!(format!("Hello from {}", request.agent_name)),
            context: json!({"prompt": request.prompt}),
        })
    }
}

#[derive(Debug, Deserialize, JsonSchema, PartialEq)]
struct Output {
    greeting: String,
}

#[tokio::test]
async fn workflow_executes_with_scripted_runner() {
    let workflow = parse_inline_workflow! {
        provider openai {
            driver: "openai"
            endpoint: "https://api.openai.com/v1"
            api_key: "test-api-key"
            models: ["model-a"]
        }

        agent greeting {
            model: openai("model-a")
            prompt: "Say hello"
            output: string
        }

        output {
            greeting: agent.greeting
        }
    };

    let runtime = WorkflowRuntime::<(), Output>::new(workflow).expect("runtime should compile");
    let execution_result = runtime
        .run_with_runner((), &ScriptedRunner)
        .await
        .expect("workflow should execute successfully");

    assert_eq!(
        execution_result,
        Output {
            greeting: "Hello from greeting".to_string(),
        }
    );
}
```

## What to test explicitly

- parse success for representative samples
- validation failures for known bad inputs
- prompt interpolation behavior
- output type mismatches
- dependency ordering in multi-agent flows
