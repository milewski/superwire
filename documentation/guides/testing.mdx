---
title: Testing Workflows
description: Parse, validate, and execute workflows in Rust tests with deterministic providers.
---

The Rust API supports three useful testing layers.

## Parse-only tests

Use parse tests when you want fast syntax coverage.

```rust
use engine_ai_core::dsl::parse_workflow;

#[test]
fn workflow_parses() {
    let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
    let workflow = parse_workflow(workflow_source).expect("workflow should parse");

    assert!(!workflow.declarations().is_empty());
}
```

## Validation tests

Use validation tests when you want to check names, references, or secret-safety rules without calling a provider.

```rust
use engine_ai_core::dsl::{parse_workflow, validate_workflow};

#[test]
fn workflow_validates() {
    let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
    let workflow = parse_workflow(workflow_source).expect("workflow should parse");
    let report = validate_workflow(&workflow);

    assert!(report.is_valid(), "{report:?}");
}
```

## Runtime tests with scripted outputs

The most practical execution test pattern uses `ScriptedProviderFactory` so you can assert output wiring without a live model.

```rust
use engine_ai_core::runtime::{ScriptedProviderFactory, WorkflowRuntime};
use serde_json::{json, Value};
use std::collections::HashMap;

#[tokio::test]
async fn workflow_executes_with_scripted_provider() {
    let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
    let mut outputs_by_agent_name = HashMap::<String, Value>::new();

    outputs_by_agent_name.insert(
        "greeting".to_owned(),
        Value::String("Hello from scripted runtime".to_owned()),
    );

    let runtime = WorkflowRuntime::new(ScriptedProviderFactory::new(outputs_by_agent_name));
    let execution_result = runtime
        .execute_source(workflow_source, json!({}), json!({}))
        .await
        .expect("workflow should execute successfully");

    assert_eq!(
        execution_result.output,
        json!({
            "greeting": "Hello from scripted runtime"
        })
    );
}
```

## What to test explicitly

- parse success for representative samples
- validation failures for known bad inputs
- prompt interpolation behavior
- output type mismatches
- dependency ordering in multi-agent flows
