---
title: Batch Imports
description: Import several MCP tools with shared bindings.
---

When many tools come from the same MCP namespace and share bindings, import them in one block.

```wire
from mcp.tasks.tool {
    bindings {
        project_id: input.project_id
        workspace_id: input.workspace_id
    }

    tool fetch_task
    tool update_task_status
    tool create_comment
}
```

This is equivalent to importing each tool separately with the same `bindings` block.

## Per-tool overrides

A tool can still add specific configuration:

```wire
from mcp.tasks.tool {
    bindings {
        project_id: input.project_id
    }

    tool fetch_task {
        max_calls: 5
    }

    tool create_comment {
        input {
            task_id: number
            body: string
        }
        max_calls: 1
    }
}
```

## Agent usage

```wire
agent task_manager {
    model: ai("pro")
    uses: [
        tool.fetch_task,
        tool.update_task_status,
        tool.create_comment
    ]
    instruction: "Manage task {{ input.task_id }}."
    output: {
        result: string
    }
}
```

Batch imports keep workflow files short without hiding which tools are available.
