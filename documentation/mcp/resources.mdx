---
title: Resources
description: Import and read MCP resources as workflow context.
---

Resources expose external context that can be read during execution.

```wire
resource project_readme from mcp.docs.resource.project_readme
```

Read a resource in a dynamic block:

```wire
dynamic {
    readme: read resource.project_readme
}
```

Then reference the dynamic value from an agent:

```wire
agent summarize_project {
    model: ai("flash")
    instruction: "Summarize this project readme: {{ dynamic.readme }}"
    output: {
        summary: string
    }
}
```

Use resources for stable context. Use tools when the workflow needs parameterized execution.
