---
title: MCP Servers
description: Connect a workflow to external tools, resources, and prompts.
---

An `mcp` declaration names an MCP server endpoint. Tool, resource, and prompt imports can then reference it.

```wire
secrets {
    mcp_summarizer_endpoint: string
}

mcp summarizer {
    endpoint: secrets.mcp_summarizer_endpoint
}
```

The endpoint value usually comes from the executor `secrets` object:

```json
{
  "secrets": {
    "mcp_summarizer_endpoint": "http://localhost:8000/mcp/summarizer"
  }
}
```

## Import kinds

```wire
tool fetch_task from mcp.summarizer.tool.fetch_task
resource project_readme from mcp.summarizer.resource.project_readme
prompt writer_instructions from mcp.summarizer.prompt.writer_instructions
```

Use tools when the workflow must call a function, resources when it must read external context, and prompts when an MCP server owns reusable instruction text.
