---
title: Prompts
description: Import reusable prompt templates from MCP servers.
---

Prompts let an external MCP server own shared instructions.

```wire
prompt writer_instructions from mcp.docs.prompt.writer_instructions
```

Render a prompt in a dynamic block:

```wire
dynamic {
    instructions: render prompt.writer_instructions
}
```

Use the rendered prompt in an agent instruction:

```wire
agent writer {
    model: ai("flash")
    instruction: "{{ dynamic.instructions }}\n\nTopic: {{ input.topic }}"
    output: {
        article: string
    }
}
```

Prompt rendering is useful when several workflows share the same system-level guidance.
