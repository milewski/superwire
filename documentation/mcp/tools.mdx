---
title: Tools
description: Import external functions and make them available to agents or dynamic blocks.
---

Tools connect workflows to external systems such as APIs, databases, task stores, and calculators.

## Import one tool

```wire
mcp tasks {
    endpoint: secrets.mcp_summarizer_endpoint
}

tool fetch_task from mcp.tasks.tool.fetch_task
```

## Declare schemas and bindings

```wire
tool fetch_task from mcp.tasks.tool.fetch_task {
    input {
        task_id: number
    }
    output {
        title: string
        description: string
    }
    bindings {
        project_id: input.project_id
    }
    max_calls: 3
}
```

Use `bindings` for values that should always be supplied by the workflow rather than the model.

## Call tools in dynamic blocks

```wire
dynamic {
    task: call tool.fetch_task {
        input {
            task_id: input.task_id
        }
    }
}
```

## Allow agents to call tools

Agents use the `uses:` array to declare tool access.

```wire
agent researcher {
    model: ai("pro")
    uses: [tool.fetch_task]
    instruction: "Fetch the task if needed, then summarize it."
    output: {
        summary: string
        missing_context: boolean
    }
}
```

Tools not listed in `uses:` are not available to that agent.
