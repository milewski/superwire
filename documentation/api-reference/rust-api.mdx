---
title: Rust API
description: Parse, validate, and execute Engine AI workflows from Rust.
---

The public Rust surface is centered around two modules:

- `engine_ai_core::dsl`
- `engine_ai_core::runtime`

## Parse and validate

```rust
use engine_ai_core::dsl::{parse_workflow, validate_workflow};

let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
let workflow = parse_workflow(workflow_source)?;
let validation_report = validate_workflow(&workflow);

assert!(validation_report.is_valid());
```

## Execute with built-in providers

```rust
use engine_ai_core::dsl::parse_workflow;
use engine_ai_core::runtime::execute_workflow_without_input;
use schemars::JsonSchema;
use serde::Deserialize;

#[derive(Debug, Deserialize, JsonSchema)]
struct Output {
    greeting: String,
}

let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
let workflow = parse_workflow(workflow_source)?;
let workflow_output: Output = execute_workflow_without_input(&workflow).await?;
```

## Execute with explicit input and secrets

```rust
use engine_ai_core::dsl::parse_workflow;
use engine_ai_core::runtime::execute_workflow;
use schemars::JsonSchema;
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, JsonSchema)]
struct Input {
    topic: String,
}

#[derive(Debug, Deserialize, JsonSchema)]
struct Output {
    summary: String,
}

let workflow_source = include_str!("../../crates/core/workflows/structured_output.ai");
let workflow = parse_workflow(workflow_source)?;

let workflow_output: Output = execute_workflow(
    &workflow,
    Input {
        topic: "agent workflows".to_string(),
    },
)
.await?;
```

## Runtime types

Useful runtime exports include:

- `WorkflowRuntime`
- `WorkflowRuntimeError`
- `execute_workflow`
- `execute_workflow_without_input`
- `AgentRunner`
- `AgentExecutionRequest`
- `AgentExecutionResult`
- `ProviderDriver`
- `ProviderConfig`

## Macro helper

The crate exports `try_workflow!` for already-parsed workflows.

```rust
use engine_ai_core::try_workflow;
```
