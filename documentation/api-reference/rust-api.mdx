---
title: Rust API
description: Parse, validate, and execute workflows from Rust when embedding the runtime directly.
---

The Docker executor is the recommended path for application integration. The Rust API is useful for embedding Superwire in another Rust service, adding providers, or writing runtime-level tests.

## Typical responsibilities

- parse `.wire` source into an AST
- validate declarations, references, schemas, and dependencies
- execute workflows with a provider runner
- build custom runners for deterministic tests

## Example shape

```rust
use superwire_core::dsl::{parse_workflow, validate_workflow};

let workflow = parse_workflow(source)?;
let report = validate_workflow(&workflow);

if !report.is_valid() {
    panic!("invalid workflow: {:?}", report.issues);
}
```

Prefer [Executor API](/api-reference/executor-api) for product integration unless you need direct runtime control.
