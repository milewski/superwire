---
title: Rust API
description: Parse, validate, and execute Engine AI workflows from Rust.
---

The public Rust surface is centered around two modules:

- `engine_ai_core::dsl`
- `engine_ai_core::runtime`

## Parse and validate

```rust
use engine_ai_core::dsl::{parse_workflow, validate_workflow};

let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
let workflow = parse_workflow(workflow_source)?;
let validation_report = validate_workflow(&workflow);

assert!(validation_report.is_valid());
```

## Execute with built-in providers

```rust
use engine_ai_core::runtime::try_workflow_from_source;
use serde::Deserialize;

#[derive(Debug, Deserialize)]
struct Output {
    greeting: String,
}

let workflow_source = include_str!("../../crates/core/workflows/minimum.ai");
let workflow_result: Result<Output, _> = try_workflow_from_source(workflow_source).await?;
let workflow_output = workflow_result?;
```

## Execute with explicit input and secrets

```rust
use engine_ai_core::runtime::try_workflow_from_source_with_values;
use serde_json::json;

let execution_result = try_workflow_from_source_with_values::<serde_json::Value>(
    workflow_source,
    json!({"topic": "agent workflows"}),
    json!({"openai_api_key": "secret"}),
)
.await?;
```

## Runtime types

Useful runtime exports include:

- `WorkflowRuntime`
- `WorkflowExecutionResult`
- `WorkflowRuntimeError`
- `ValidationProblem`
- `DefaultProviderFactory`
- `ScriptedProviderFactory`
- `WorkflowProviderFactory`
- `DynamicProvider`
- `try_workflow_from_source`
- `try_workflow_from_source_with_values`

## Macro helper

The runtime also re-exports `try_workflow!` for source-included workflows.

```rust
use engine_ai_core::runtime::try_workflow;
```
