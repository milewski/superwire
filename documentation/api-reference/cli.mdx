## Installation

```bash
cargo install engine-ai
```

## Basic Commands

### Run Workflow

```bash
engine-ai run workflow.ai
```

### Check Syntax

```bash
engine-ai check workflow.ai
```

### Show Version

```bash
engine-ai --version
```

### Show Help

```bash
engine-ai --help
```

## Run Command

Execute a workflow file:

```bash
engine-ai run <file>
```

Options:
- `--verbose, -v`: Enable verbose output
- `--quiet, -q`: Suppress non-essential output
- `--output, -o <format>`: Output format (json, yaml, text)

Examples:

```bash
# Run with verbose output
engine-ai run workflow.ai --verbose

# Output as JSON
engine-ai run workflow.ai --output json

# Quiet mode
engine-ai run workflow.ai --quiet
```

## Check Command

Validate workflow syntax:

```bash
engine-ai check <file>
```

Examples:

```bash
# Check syntax
engine-ai check workflow.ai

# Check multiple files
engine-ai check workflow1.ai workflow2.ai
```

## Format Command

Format workflow files:

```bash
engine-ai format <file>
```

Options:
- `--write, -w`: Write formatted output to file
- `--check`: Check if file is formatted

Examples:

```bash
# Format and print
engine-ai format workflow.ai

# Format and write
engine-ai format workflow.ai --write

# Check formatting
engine-ai format workflow.ai --check
```

## Environment Variables

- `ENGINE_AI_LOG`: Set log level (debug, info, warn, error)
- `ENGINE_AI_CONFIG`: Path to config file

Examples:

```bash
# Enable debug logging
ENGINE_AI_LOG=debug engine-ai run workflow.ai

# Use custom config
ENGINE_AI_CONFIG=~/.engine-ai/custom.toml engine-ai run workflow.ai
```

## Configuration File

Create `~/.engine-ai/config.toml`:

```toml
[execution]
max_parallel_agents = 10
timeout_seconds = 300

[providers.ollama]
endpoint = "http://localhost:11434"
default_model = "qwen3:8b"
```
