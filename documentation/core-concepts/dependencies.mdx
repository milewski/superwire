---
title: Dependencies
description: Learn how references create the execution graph.
---

Superwire derives dependencies from references. You do not manually declare execution order.

```wire
agent collect_facts {
    model: ai("flash")
    instruction: "Collect facts about {{ input.topic }}."
    output: {
        facts: [string]
    }
}

agent write_summary {
    model: ai("flash")
    instruction: "Summarize these facts: {{ agent.collect_facts.facts }}"
    output: {
        summary: string
    }
}

output {
    summary: agent.write_summary.summary
}
```

`write_summary` depends on `collect_facts` because it references `agent.collect_facts.facts`.

## Parallel execution

Independent agents can run at the same time:

```wire
agent extract_risks {
    model: ai("flash")
    instruction: "List risks for {{ input.topic }}."
    output: {
        risks: [string]
    }
}

agent extract_actions {
    model: ai("flash")
    instruction: "List actions for {{ input.topic }}."
    output: {
        actions: [string]
    }
}
```

If a later agent references both, it waits for both to complete.

## Validation

Validation reports:

- unknown references
- invalid field paths
- dependency cycles
- schema references that do not exist
- attempts to use tools that were not imported or not listed in `uses:`
