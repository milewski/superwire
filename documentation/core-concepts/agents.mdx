title: Agents

Agents are the center of the DSL. They describe a named unit of work that can reference input, secrets, and prior agent outputs.

## Basic syntax

```ai
agent summary {
    model: openai("gpt-4.1-mini")
    prompt: "Summarize {{ input.notes }}."
    output: string
}
```

## Agent declaration form

```ai
agent <name> [for <item> in <expression>] {
    model: <expression>
    prompt: <expression>
    output: <type_expression>
    context: <expression>
    inference: <expression>
    tools: <expression>
    <custom_property>: <expression>
}
```

## Built-in properties

- **`model`**: provider/model binding such as `openai("gpt-4.1-mini")`
- **`prompt`**: string literal or interpolated string sent to the model
- **`output`**: type expression used to validate the returned JSON value
- **`context`**: reserved property for explicit context wiring
- **`inference`**: structured generation settings such as temperature and token limits
- **`tools`**: list of tool references such as `tool.search` or `tool.search(query: input.topic)`
- **custom properties**: additional named expressions preserved in the AST

## A full example

```ai
agent research_brief {
    model: openai("gpt-4.1-mini")

    inference: {
        temperature: 0.2
        max_tokens: 12_000
    }

    prompt: "Write a concise research brief about {{ input.topic }}."

    output: {
        summary: string
        risks: [string]
        next_steps: [string; 3]
    }
}
```

## References inside agents

Agent expressions can use:

- `input.field`
- `secrets.field`
- `agent.other_agent`
- `agent.other_agent.field`
- `agent.other_agent.nullable_field?.nested_field`

Referencing `agent.other_agent` creates a dependency edge automatically.

## Loop form

The grammar also supports agent loops:

```ai
agent remediation_plan for finding in agent.findings.items {
    model: openai("gpt-4.1-mini")
    prompt: "Create a remediation plan for {{ finding }}."
    output: string
}
```

## Current runtime behavior

The default runtime currently consumes these agent fields directly:

- `model`
- `prompt`
- `output`
- `context`
- `inference`
- optional `for` loop iteration

It parses and validates the rest, but does not yet execute `tools` / `tool.*` references.
