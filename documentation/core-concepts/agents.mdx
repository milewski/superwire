---
title: Agents
description: Define model calls, tool access, context, and structured outputs.
---

An agent is one LLM step in the workflow graph.

```wire
agent summarize_task {
    model: ai("flash")
    instruction: "Summarize task {{ input.task_id }}."
    output: {
        summary: string
        next_action: string
    }
}
```

## Agent properties

| Property | Purpose |
| --- | --- |
| `model` | Selects a provider model alias, for example `ai("flash")`. |
| `instruction` | Text sent to the model. Supports interpolation. |
| `context` | Optional structured context supplied to the model. |
| `uses` | Tools the agent is allowed to call. |
| `output` | Required object-shaped output schema. |

## Structured outputs

Agent outputs are always object-shaped. Keep field names stable because other agents and final outputs reference them.

```wire
agent classify {
    model: ai("flash")
    instruction: "Classify: {{ input.message }}"
    output: {
        category: enum { bug, feature, question }
        confidence: number
    }
}
```

Downstream references use dot paths:

```wire
agent route {
    model: ai("flash")
    instruction: "Route category {{ agent.classify.category }} with confidence {{ agent.classify.confidence }}."
    output: {
        assignee: string
        reason: string
    }
}
```

## Tool access

Tools must be imported and explicitly listed in `uses:`.

```wire
tool search_tasks from mcp.tasks.tool.search_tasks

agent researcher {
    model: ai("pro")
    uses: [tool.search_tasks]
    instruction: "Research task {{ input.task_id }} before answering."
    output: {
        findings: [string]
    }
}
```

## Looped agents

Use `for ... in` to run the same agent over a collection. Iterations can run in parallel.

```wire
input {
    task_ids: [number]
}

agent summarize_each for task_id in input.task_ids {
    model: ai("flash")
    instruction: "Summarize task {{ task_id }}."
    output: {
        task_id: number
        summary: string
    }
}

output {
    summaries: agent.summarize_each
}
```
