---
title: Workflows
description: Understand the anatomy of a complete .wire file.
---

A workflow file is a sequence of declarations. The order is chosen for readability; dependencies are discovered from references.

## Recommended order

1. `secrets`
2. `input`
3. `schema`
4. `provider`
5. `mcp`, `tool`, `resource`, and `prompt` imports
6. `dynamic` blocks
7. `agent` blocks
8. final `output`

## Complete example

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

input {
    project_id: number
    task_id: number
}

schema task_brief {
    title: string
    summary: string
    risk: enum { low, medium, high }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

agent create_brief {
    model: ai("flash")
    instruction: "Create a task brief for task {{ input.task_id }}."
    output: schema.task_brief
}

output {
    project_id: input.project_id
    task_id: input.task_id
    brief: agent.create_brief
}
```

## Final output

The final `output` block is the public JSON response returned by `/execute` and the payload in the final `/execute/stream` completion event.

```wire
output {
    task_id: input.task_id
    title: agent.create_brief.title
    summary: agent.create_brief.summary
}
```
