---
title: Schemas
description: Define reusable output types with arrays, enums, variants, tuples, and inline descriptions.
---

Schemas let you name complex type expressions and reuse them in agent outputs, input fields, and other schemas.

## Named schemas

Schema names must be lowercase `snake_case`:

```wire
schema participant {
    name: string
    role: string
}

schema research_summary {
    title: string
    lead: schema.participant
    participants: [schema.participant]
}
```

<Warning>
  Schema names must use `snake_case`. Invalid: `schema Participant`, `schema researchSummary`.
</Warning>

## Where schemas can be used

- inside another schema
- inside `input`
- inside `secrets`
- as an agent `output`

```wire
input {
    lead_participant: schema.participant
    previous_summary: schema.research_summary
}

agent summarize {
    model: ollama("qwen3.5:32b")
    instruction: "Summarize the provided research context."
    output: schema.research_summary
}
```

## Field descriptions

Use doc comments before fields:

```wire
schema release_note {
    /// Short human-readable title
    title: string

    /// Severity bucket
    impact: enum {
        low
        medium
        high
    }
}
```

The parser stores these descriptions in the AST so schema-aware tooling can use them.

## Supported type forms

- primitive scalars: `string`, `number`, `float`, `boolean`, `object`
- nullable values: `maybe T`
- schema references: `schema.name`
- arrays: `[string]`
- fixed-length arrays: `[string; 3]`
- tuples: `(string, number, [string; 3])`
- objects: `{ title: string, score: number }`
- enums: `enum { draft, ready, published }`
- variants: `variant tag { ... }`

## Practical example

```wire
schema all_types {
    /// A basic string value
    string_value: string

    /// Required but may be null
    nullable_string: maybe string

    /// Exactly three strings
    fixed_array: [string; 3]

    /// Mixed tuple
    tuple_value: (string, number, [string; 3])

    /// Nested object
    object_value: {
        name: string
        score: number
    }

    /// Fixed string choices
    enum_value: enum {
        draft
        ready
        published
    }
}
```

## Validation rules

Validation checks that every `schema.name` reference points to a declared schema. Unknown schema references are reported with source spans.
