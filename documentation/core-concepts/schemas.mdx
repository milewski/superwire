---
title: Schemas
description: Define reusable structured types.
---

Schemas name reusable object shapes and nested fields. Schema names should be lowercase snake_case.

```wire
schema participant {
    name: string
    role: string
}

schema research_summary {
    title: string
    lead: schema.participant
    contributors: [schema.participant]
}
```

A schema declaration always opens a block. It does not assign a type expression with `=`.

## Using schemas

```wire
input {
    requester: schema.participant
}

agent summarize {
    model: ai("flash")
    instruction: "Create a summary for {{ input.requester.name }}."
    output: schema.research_summary
}
```

## Shared enum fields

Use a shared schema when multiple structures need the same enum.

```wire
schema shared {
    status: enum {
        draft
        ready
        published
    }
}

schema article {
    title: string
    status: schema.shared.status
}
```

Inline enum members use commas when written on one line:

```wire
status: enum { draft, ready, published }
```

When enum members are separated by new lines, commas are not required:

```wire
status: enum {
    draft
    ready
    published
}
```

## Field descriptions

Descriptions are preserved for schema-aware tooling and can improve structured output quality.

```wire
schema release_note {
    title: string "Short title shown to the user"
    impact: enum { low, medium, high } "Severity bucket"
}
```
