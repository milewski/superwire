---
title: Ollama
description: Configure the built-in Ollama driver in the default Engine AI runtime.
---

The default provider factory includes an Ollama driver.

## Minimal configuration

```txt
provider ollama {
    driver: "ollama"
    models: ["qwen3.5:8b"]
}
```

## Explicit endpoint configuration

```txt
provider ollama {
    driver: "ollama"
    api_endpoint: "http://localhost:11434"
    models: ["qwen3.5:8b", "qwen3.5:32b"]
}
```

The built-in factory accepts any of these endpoint keys:

- `api_endpoint`
- `base_url`
- `host`

If none are supplied, it defaults to `http://localhost:11434`.

## Agent example

```txt
agent greeting {
    model: ollama("qwen3.5:8b")
    prompt: "Write a short welcome message."
    output: string
}
```

## Operational notes

- keep `models` aligned with what you have pulled locally
- if you change ports, prefer `api_endpoint` for clarity
- declare only models you want workflow authors to use
