---
title: Ollama
description: Use a local Ollama server when developing or testing locally.
---

Ollama is useful for local development when you do not want to call a remote provider.

```wire
provider local_ai {
    driver: "ollama"
    endpoint: "http://host.docker.internal:11434"
    models: {
        flash: "llama3.1"
    }
}

agent local_summary {
    model: local_ai("flash")
    instruction: "Summarize {{ input.topic }}."
    output: {
        summary: string
    }
}
```

When running the executor in Docker, make sure the container can reach the Ollama host. On Linux you may need to use host networking or an explicit Docker bridge address.
