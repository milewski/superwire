## Overview

Ollama provides local LLM inference with no API costs, perfect for development and testing.

## Installation

<Tabs>
  <Tab title="macOS">
    ```bash
    brew install ollama
    ```
  </Tab>
  <Tab title="Linux">
    ```bash
    curl -fsSL https://ollama.com/install.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    Download from [ollama.com/download](https://ollama.com/download)
  </Tab>
</Tabs>

## Start Ollama

```bash
ollama serve
```

## Pull Models

```bash
# Pull a model
ollama pull qwen3:8b

# List available models
ollama list

# Remove a model
ollama rm qwen3:8b
```

## Configuration

```ai
provider ollama {
    driver <- "ollama"
    config <- {
        endpoint <- "http://localhost:11434"
    }
    models <- ["qwen3:8b", "llama2:7b", "mistral:7b"]
}
```

## Popular Models

- `qwen3:8b` - Fast, capable 8B parameter model
- `llama2:7b` - Meta's Llama 2 7B
- `llama2:13b` - Larger Llama 2 variant
- `mistral:7b` - Mistral 7B
- `codellama:13b` - Code-specialized model
- `phi3:mini` - Small, efficient model

## Using Ollama

```ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

<- agent task {
    model <- "ollama/qwen3:8b"
    prompt <- "Hello, world!"
}
```

## Custom Endpoint

```ai
provider ollama {
    driver <- "ollama"
    config <- {
        endpoint <- "http://custom-server:11434"
    }
    models <- ["qwen3:8b"]
}
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection refused">
    Ensure Ollama is running:
    ```bash
    ollama serve
    ```
  </Accordion>

  <Accordion title="Model not found">
    Pull the model first:
    ```bash
    ollama pull qwen3:8b
    ```
  </Accordion>

  <Accordion title="Slow performance">
    - Use smaller models (7B instead of 13B)
    - Ensure sufficient RAM
    - Check CPU/GPU usage
  </Accordion>
</AccordionGroup>
