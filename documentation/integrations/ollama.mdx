---
title: Ollama
description: Configure Superwire to use an Ollama instance as a model provider.
---

[Ollama](https://ollama.com) runs large language models locally on your machine.

## Setup

Install Ollama and pull a model:

```bash
ollama pull qwen3.5:8b
```

## Provider declaration

```wire
provider ollama from ollama {
endpoint: "http://localhost:11434"
}

model ollama_model from ollama {
    id: "qwen3.5:8b"
}
```

## Required settings

| Setting | Description |
| --- | --- |
| `driver` | Must be `"ollama"` |
| `endpoint` | Host and port (e.g., `http://localhost:11434`) |

## Optional settings

| Setting | Description |
| --- | --- |
| `models` | List of allowed model names for validation |
| `api_key` | Usually not required for local Ollama |

## Agent binding

```wire
agent greeting {
    model: model.ollama_model
    instruction: "Write a welcome message."
    output: string
}
```

<Tip>
  Use the `models` list in your provider declaration to catch typos at
  validation time before sending a request to Ollama.
</Tip>
