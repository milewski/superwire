---

The runtime includes a built-in Ollama driver.

## Required configuration

```ai-dsl
provider ollama {
    driver: "ollama"
    endpoint: "http://localhost:11434"
    models: ["qwen3.5:8b", "qwen3.5:32b"]
}
```

Required runtime settings:

- `driver`
- `endpoint` (must include host and port)

Optional validation setting:

- `models`

## Agent example

```ai-dsl
agent greeting {
    model: ollama("qwen3.5:8b")
    prompt: "Write a short welcome message."
    output: string
}
```

## Operational notes

- keep `models` aligned with models available in your Ollama instance
- use explicit `endpoint` values for non-default hosts or ports
- declare only models you want workflow authors to use
