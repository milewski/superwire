---
title: OpenAI-Compatible Endpoints
description: Configure the built-in OpenAI driver with explicit endpoint and API key settings.
---

The runtime includes a built-in OpenAI-compatible driver.

## Required configuration

```wire
provider openai {
    driver: "openai"
    endpoint: "https://api.openai.com/v1"
    api_key: "test-api-key"
    models: ["gpt-4.1-mini"]
}
```

Required runtime settings:

- `driver`
- `endpoint`
- `api_key`

Optional validation setting:

- `models`

## Agent example

```wire
agent analyst {
    model: openai("gpt-4.1-mini")
    prompt: "Analyze {{ input.notes }} and return the main risks."
    output: {
        risks: [string]
    }
}
```

## Notes

- `endpoint` should include the API base path expected by your OpenAI-compatible service
- `api_key` is parsed as a string literal by the current runtime provider parser
- built-in drivers are currently `openai` and `ollama`
