## Overview

OpenAI provides access to powerful GPT models including GPT-4, GPT-4 Turbo, and GPT-3.5 Turbo.

## Get API Key

1. Go to [platform.openai.com](https://platform.openai.com)
2. Sign up or log in
3. Navigate to API Keys
4. Create a new API key

## Configuration

```ai
provider openai {
    driver <- "openai"
    config <- {
        api_key <- "sk-proj-..."
        endpoint <- "https://api.openai.com/v1"
    }
    models <- ["gpt-4", "gpt-4-turbo", "gpt-3.5-turbo"]
}
```

## Available Models

- `gpt-4` - Most capable model
- `gpt-4-turbo` - Faster GPT-4 variant
- `gpt-3.5-turbo` - Fast and cost-effective
- `gpt-4o` - Optimized GPT-4

## Using OpenAI

```ai
provider openai {
    driver <- "openai"
    config <- {
        api_key <- "sk-proj-..."
        endpoint <- "https://api.openai.com/v1"
    }
    models <- ["gpt-4"]
}

<- agent task {
    model <- "openai/gpt-4"
    prompt <- "Explain quantum computing"
}
```

## Custom Endpoints

Use OpenAI-compatible endpoints:

```ai
provider opencode {
    driver <- "openai"
    config <- {
        api_key <- "your-api-key"
        endpoint <- "https://opencode.ai/zen/v1"
    }
    models <- ["zen-bigpickle"]
}

<- agent task {
    model <- "opencode/zen-bigpickle"
    prompt <- "Your prompt here"
}
```

## Best Practices

<Tip>
  Use GPT-3.5 Turbo for simple tasks to reduce costs.
</Tip>

<Warning>
  Keep your API key secure. Never commit it to version control.
</Warning>

<Info>
  Monitor your usage at [platform.openai.com/usage](https://platform.openai.com/usage)
</Info>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Invalid API key">
    - Verify your API key is correct
    - Check if the key has been revoked
    - Ensure you have billing set up
  </Accordion>

  <Accordion title="Rate limits">
    - Reduce parallel agent execution
    - Upgrade your API tier
    - Add delays between requests
  </Accordion>

  <Accordion title="Model not found">
    - Check model name spelling
    - Verify model is available in your region
    - Ensure you have access to the model
  </Accordion>
</AccordionGroup>
