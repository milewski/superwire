---
title: OpenAI-Compatible Endpoints
description: Configure the built-in OpenAI driver with API keys, custom base URLs, and model allowlists.
---

The default provider factory includes an OpenAI-compatible driver.

## Minimal cloud configuration

```txt
provider openai {
    driver: "openai"
    models: ["gpt-4.1-mini"]
}
```

With this configuration, the runtime falls back to `OPENAI_API_KEY`.

## Explicit API key and base URL

```txt
secrets {
    openai_api_key: string
}

provider openai {
    driver: "openai"
    api_key: secrets.openai_api_key
    base_url: "https://api.openai.com/v1"
    models: ["gpt-4.1-mini", "gpt-4.1"]
}
```

## Agent example

```txt
agent analyst {
    model: openai("gpt-4.1-mini")
    prompt: "Analyze {{ input.notes }} and return the main risks."
    output: {
        risks: [string]
    }
}
```

## Notes

- `api_key` overrides the environment fallback
- `base_url` and `api_endpoint` are interchangeable in the default factory
- the current built-in drivers are `openai` and `ollama`
- Anthropic is not built into the current default provider factory
