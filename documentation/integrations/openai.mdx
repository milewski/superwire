---
title: OpenAI-Compatible Providers
description: Configure OpenAI-compatible endpoints such as OpenAI, DashScope compatible mode, and internal gateways.
---

Use the `openai` driver for endpoints that expose an OpenAI-compatible chat/completions API.

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}
```

Example executor secrets:

```json
{
  "endpoint": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "api_key": "YOUR_API_KEY",
  "models": {
    "flash": "qwen3.6-plus",
    "pro": "qwen3.6-plus",
    "max": "qwen3.6-plus"
  }
}
```

Agents reference aliases, not concrete model strings:

```wire
agent answer {
    model: ai("flash")
    instruction: "Answer: {{ input.question }}"
    output: {
        answer: string
    }
}
```
