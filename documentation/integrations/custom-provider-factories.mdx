---
title: Custom Provider Factories
description: Advanced embedding notes for custom provider implementations.
---

Most applications should use the Docker executor and an OpenAI-compatible endpoint. Custom provider factories are only needed when embedding the runtime directly or adding a new provider driver.

A custom provider should expose the same behavior expected by workflow provider declarations:

```wire
provider ai {
    driver: "custom"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
    }
}
```

Implementation details belong in the Rust API layer. Keep public workflows provider-agnostic by using stable model aliases such as `flash`, `pro`, and `max`.
