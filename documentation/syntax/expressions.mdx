---
title: Expressions
description: Values and operations used inside declarations.
---

Expressions appear in provider settings, dynamic blocks, agent instructions, context blocks, and final outputs.

## Literals

```wire
"hello"
123
12.5
true
false
```

## References

```wire
input.topic
secrets.api_key
agent.extract.summary
dynamic.project_context
```

## Arrays and objects

```wire
["bug", "feature", "question"]

{
    project_id: input.project_id
    task_id: input.task_id
}
```

## Function-like bindings

Providers and models are selected with a call-like expression:

```wire
model: ai("flash")
```

Tools are called in `dynamic` blocks:

```wire
dynamic {
    task: call tool.fetch_task {
        input {
            task_id: input.task_id
        }
    }
}
```

Resources and prompts use dedicated expression forms:

```wire
dynamic {
    readme: read resource.project_readme
    instructions: render prompt.writer_instructions
}
```
