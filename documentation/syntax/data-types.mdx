---
title: Data Types
description: The complete type system used by input, secrets, schemas, and agent output declarations.
---

Superwire uses the same type expression grammar in four places:

- `input { ... }`
- `secrets { ... }`
- `schema Name { ... }`
- `agent name { output: ... }`

## Primitive types

```wire
string
number
float
boolean
null
```

## Schema references

```wire
schema Participant {
    name: string
    role: string
}

schema ResearchSummary {
    lead: schema.Participant
    participants: [schema.Participant]
}
```

## Arrays

```wire
[string]
[number]
[{ id: string, score: number }]
```

### Fixed-length arrays

```wire
[string; 3]
```

Validation enforces the exact array length.

## Tuples

```wire
(string, number, [string; 3])
```

Tuples validate both order and length.

## Objects

```wire
{
    title: string
    score: number
}
```

## Unions

```wire
string | null
schema.Participant | null
"draft" | "ready" | "published"
```

## String enums

String literals inside type expressions create exact string enum members.

```wire
status: "draft" | "ready" | "published"
```

## Field descriptions

You can add a trailing string description to any typed field.

```wire
output: {
    title: string "Short title shown to the reader"
    score: number "Confidence score from 0 to 100"
}
```

## Practical example

```wire
schema AllTypes {
    string_value: string "A basic string value"
    nullable_number: number | null "Required but may be null"
    fixed_array: [string; 3] "Exactly three strings"
    tuple_value: (string, number, [string; 3]) "Mixed tuple"
    object_value: {
        string_value: string
        number_value: number
    } "Nested object"
    enum_value: "draft" | "ready" | "published" "Fixed string choices"
}
```
