---
title: Data Types
description: Primitive, object, array, tuple, enum, and schema reference types.
---

Superwire types describe `input`, `secrets`, schema fields, and agent outputs.

## Primitives

```wire
string
number
float
boolean
```

## Objects

```wire
{
    title: string
    score: number
}
```

Inline object fields use commas:

```wire
{ title: string, score: number }
```

## Arrays

```wire
[string]
[number]
[schema.participant]
```

Fixed-length arrays use a semicolon:

```wire
[string; 3]
```

## Tuples

```wire
(string, number)
(string, number, [string; 3])
```

## Enums

```wire
enum { draft, ready, published }
```

Or multiline:

```wire
enum {
    draft
    ready
    published
}
```

## Schema references

```wire
schema participant {
    name: string
    role: string
}

schema article {
    title: string
    author: schema.participant
}
```

## Practical schema

```wire
schema task_result {
    task_id: number
    status: enum { todo, doing, done }
    labels: [string]
    confidence: number
    owner: {
        name: string
        role: string
    }
}
```
