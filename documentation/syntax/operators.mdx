## Dot access

Use dot access to read nested fields.

```wire
input.project_id
secrets.models.flash
agent.summarize.summary
```

## Model call

```wire
model: ai("flash")
```

Model options can be placed in a block after the model call:

```wire
model: ai("pro") {
    temperature: 0.2
    max_tokens: 1000
}
```

## Tool call

```wire
call tool.fetch_task {
    input {
        task_id: input.task_id
    }
}
```

## Inline separators

Use commas for inline arrays, tuples, objects, and enums:

```wire
["a", "b", "c"]
(string, number)
{ title: string, score: number }
enum { draft, ready, published }
```

When object or enum entries are on separate lines, commas are not required.
