---
title: Control Flow
description: The current grammar-level control flow features: agent for-loops and dynamic blocks.
---

The DSL supports explicit control flow through agent `for` loops and implicit flow through dynamic blocks.

## Agent for-loop syntax

```wire
agent <name> for <item_name> in <expression> {
    ...
}
```

## Example

```wire
input {
    numbers: [number]
}

agent input_number_note for n in input.numbers {
    model: model.openai_model
    instruction: "Write a short note for input number {{ n }}."
    output: {
        number: number
        note: string
    }
}
```

## Object destructuring in loops

You can destructure objects in the loop pattern:

```wire
agent process_item for { id, name } in input.items {
    model: model.openai_model
    instruction: "Process item {{ id }}: {{ name }}"
    output: string
}
```

## Common iterable sources

- input arrays: `input.items`
- agent-produced arrays: `agent.findings.items`
- dynamic block results: `dynamic.results.values`
- inline literals: `[1, 2, 3, 4]`

## Expected result shape

Referencing a looped agent returns an array of outputs:

```wire
output {
    notes: agent.input_number_note
}
```

## Current runtime status

Looped agents execute in the default runtime. Each loop iteration produces one output item, and referencing the looped agent returns the full output array. Iterations execute in parallel.
