---
title: Type Annotations
description: Where type annotations appear and how to write readable output contracts.
---

Type annotations appear after a field name:

```wire
input {
    project_id: number
    title: string
    urgent: boolean
}
```

## Field descriptions

A string after the type describes the field.

```wire
schema task_summary {
    title: string "Short display title"
    summary: string "One paragraph summary"
    priority: enum { low, medium, high } "Routing priority"
}
```

## Agent outputs

Agent output contracts are required and object-shaped:

```wire
agent summarize {
    model: ai("flash")
    instruction: "Summarize {{ input.title }}."
    output: {
        summary: string
        action_items: [string]
    }
}
```

## Reusing schemas

```wire
schema summary_output {
    summary: string
    action_items: [string]
}

agent summarize {
    model: ai("flash")
    instruction: "Summarize {{ input.title }}."
    output: schema.summary_output
}
```
