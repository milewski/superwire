---
title: Type Annotations
description: Where type annotations appear and how to write readable contracts.
---

Type annotations appear after a field name.

```wire
input {
    project_id: number
    title: string
    urgent: boolean
}
```

## Field descriptions

Use triple-slash comments for schema field descriptions.

```wire
schema task_summary {
    /// Short display title
    title: string

    /// One paragraph summary
    summary: string

    /// Routing priority
    priority: enum { low, medium, high }
}
```

## Agent outputs

Agent output contracts are required and object-shaped.

```wire
agent summarize {
    model: model.fast
    instruction: "Summarize {{ input.title }}."

    output: {
        summary: string
        action_items: [string]
    }
}
```

## Reusing schemas

```wire
schema summary_output {
    summary: string
    action_items: [string]
}

agent summarize {
    model: model.fast
    instruction: "Summarize {{ input.title }}."
    output: schema.summary_output
}
```

## Tool contracts

`input {}` and `output {}` on tools define schemas. They do not bind runtime values.

```wire
tool fetch_task from mcp.tasks.tool.fetch_task {
    input {
        task_id: number
    }

    output {
        title: string
        description: string
        status: string
    }
}
```

Runtime values are supplied with `bindings {}` at the call site.
