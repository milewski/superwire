---
title: Comments
description: Use `//` comments to annotate workflows without affecting parsing.
---

Engine AI supports single-line comments.

```txt
// Provider defines where the model comes from.
provider ollama {
    driver: "ollama"
    models: ["qwen3.5:8b"]
}
```

## Rules

- comments start with `//`
- comments run to the end of the line
- comments can appear on their own line or after a value

```txt
input {
    topic: string // Topic supplied by the caller
}
```

## Recommendation

Use comments for workflow intent and business context, not to restate obvious syntax. The best comments explain why a provider, prompt, or output shape exists.
