---
title: Comments
description: Add inline and block comments to .wire files.
---

Use `//` for line comments.

```wire
// Runtime credentials come from the executor request.
secrets {
    endpoint: string
    api_key: string
}
```

Use block comments for longer notes.

```wire
/*
This workflow creates a task summary and routes it to the next stage.
*/
agent summarize {
    model: ai("flash")
    instruction: "Summarize {{ input.task_id }}."
    output: {
        summary: string
    }
}
```
