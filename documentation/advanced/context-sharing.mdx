---
title: Context and Compaction
description: Document the `context:` property and the current grammar for `context(...)` and `compact(...)`.
---

The DSL supports a `context:` property on agents.

## Full-context syntax

```txt
agent summary_from_full_context {
    model: openai("gpt-4.1-mini")
    context: context(agent.research_analysis)
    prompt: "Write a short executive summary from the available context."
    output: string
}
```

## Compacted-context syntax

```txt
agent summary_from_default_compact_context {
    model: openai("gpt-4.1-mini")
    context: compact(agent.research_analysis)
    prompt: "Write a short executive summary from the compacted prior context."
    output: string
}
```

## Custom compaction call

```txt
agent summary_from_custom_compact_context {
    model: openai("gpt-4.1-mini")
    context: compact(
        agent: agent.research_analysis,
        model: openai("gpt-4.1-mini"),
        inference: {
            temperature: 0.1
            max_tokens: 1_500
        },
        prompt: """
            Compact this prior context for an executive summary step.
            Keep only the highest-signal themes and essential quotes.
        """
    )
    prompt: "Write a short executive summary from the customized compacted context."
    output: {
        summary: string
        top_actions: [string; 3]
    }
}
```

## What the syntax expresses

- `context(agent.name)` means reuse full prior context
- `compact(agent.name)` means derive a reduced context view
- named arguments allow the DSL to describe a custom compaction step

<Warning>
  The parser accepts these function calls and the validator traverses them for
  references and dependency edges, but the current default runtime does not
  evaluate generic function calls yet.
</Warning>

## When to use this page

Use this page as the language reference for context-related syntax. If you are writing production workflows for the current default runtime, stay with plain `prompt`, `model`, and `output` until context execution support lands.
