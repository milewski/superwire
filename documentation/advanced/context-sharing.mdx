---
title: Context Sharing
description: Share structured data between agents without duplicating instructions.
---

Agents can read from `input`, `dynamic`, and other agent outputs. Prefer structured references over copying large strings.

```wire
agent extract_context {
    model: ai("flash")
    instruction: "Extract facts from {{ input.notes }}."
    output: {
        facts: [string]
    }
}

agent write_summary {
    model: ai("flash")
    context: {
        facts: agent.extract_context.facts
    }
    instruction: "Write a concise summary from the provided context."
    output: {
        summary: string
    }
}
```

## Dynamic context

```wire
dynamic {
    task: call tool.fetch_task {
        input {
            task_id: input.task_id
        }
    }
}

agent summarize_task {
    model: ai("flash")
    context: {
        task: dynamic.task
    }
    instruction: "Summarize the task context."
    output: {
        summary: string
    }
}
```

Use `context` for structured values and `instruction` for the task the model should perform.
