---
title: Tool Calling
description: Advanced notes for controlled MCP tool access.
---

Agents do not receive every imported tool automatically. Tool access is explicit.

```wire
tool fetch_task from mcp.tasks.tool.fetch_task

agent researcher {
    model: ai("pro")
    uses: [tool.fetch_task]
    instruction: "Fetch task context and summarize it."
    output: {
        summary: string
    }
}
```

## Dynamic calls versus agent calls

Use a `dynamic` block when the workflow author decides exactly which tool to call:

```wire
dynamic {
    task: call tool.fetch_task {
        input {
            task_id: input.task_id
        }
    }
}
```

Use `uses:` when the model may decide whether and how to call the tool during the agent step.

## Guardrails

- Add `input` and `output` schemas to tool declarations when possible.
- Use `bindings` for trusted values supplied by the workflow.
- Use `max_calls` to avoid runaway external calls.
- Keep tool names descriptive and scoped to their purpose.
