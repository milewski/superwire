## Rust workspace

Superwire is currently easiest to consume from source.

```bash
git clone git@github.com:milewski/superwire.git
cd superwire
cargo test
```

## Requirements

- Rust stable toolchain
- `cargo`
- One provider backend if you want live execution

## Provider setup

### Ollama

```bash
ollama pull qwen3.5:8b
```

The default Ollama integration reads these provider settings when present:

- `driver: "ollama"`
- `endpoint: "http://localhost:11434"`
- `models: ["..."]`

`endpoint` should include host and port.

### OpenAI-compatible endpoints

The default OpenAI integration reads:

- `driver: "openai"`
- `endpoint: "https://..."`
- `api_key: "..."`
- `models: ["..."]`

## Documentation preview

To run the Mintlify docs locally:

```bash
cd documentation
npx mintlify dev
```

## Recommended first checks

- Open `crates/executor/tests/fixtures/001_minimum.wire`
- Read `/quickstart`
- Parse a workflow with `superwire_core::dsl::parse_workflow`
- Validate it with `superwire_core::dsl::validate_workflow`
