## Rust workspace

Engine AI is currently easiest to consume from source.

```bash
git clone git@github.com:milewski/engine-ai.git
cd engine-ai
cargo test
```

## Requirements

- Rust stable toolchain
- `cargo`
- One provider backend if you want live execution

## Provider setup

### Ollama

```bash
ollama pull qwen3.5:8b
```

The default Ollama integration reads these provider settings when present:

- `driver: "ollama"`
- `api_endpoint: "http://localhost:11434"`
- `base_url: "http://localhost:11434"`
- `host: "http://localhost"`
- `models: ["..."]`

If no endpoint setting is supplied, the runtime defaults to `http://localhost:11434`.

### OpenAI-compatible endpoints

The default OpenAI integration reads:

- `driver: "openai"`
- `api_key: secrets.some_key` or `OPENAI_API_KEY`
- `base_url: "https://..."`
- `api_endpoint: "https://..."`
- `models: ["..."]`

Example environment setup:

```bash
export OPENAI_API_KEY="your-api-key"
```

## Documentation preview

To run the Mintlify docs locally:

```bash
cd documentation
npx mintlify dev
```

## Recommended first checks

- Open `crates/core/workflows/minimum.ai`
- Read `/quickstart`
- Parse a workflow with `engine_ai_core::dsl::parse_workflow`
- Validate it with `engine_ai_core::dsl::validate_workflow`
