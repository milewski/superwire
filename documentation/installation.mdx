## Runtime installation

The recommended runtime is the Docker executor image:

```bash
docker pull rmilewski/superwire-executor
docker run --rm -p 8080:8080 rmilewski/superwire-executor
```

The executor starts an HTTP server with:

- `POST /execute` for a final JSON response
- `POST /execute/stream` for Server-Sent Events

## Requirements

To run workflows you need:

- Docker or another container runtime
- network access from the executor to your model provider endpoint
- a `.wire` workflow source encoded as base64
- an execution payload containing `input`, `secrets`, and `workflow_source_base64`

## Model provider setup

Superwire can call OpenAI-compatible HTTP APIs. The provider block normally reads credentials and model names from `secrets`:

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}
```

## Rust workspace

Rust is useful when embedding Superwire or contributing to the runtime. It is not required for normal executor usage.

```bash
git clone git@github.com:milewski/superwire.git
cd superwire
cargo test
```
