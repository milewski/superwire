Engine AI is a declarative language for describing agent workflows.
A workflow is a plain text file made from a small set of declarations:

- providers, which define where models come from
- input and secrets, which define typed external values
- schemas, which define reusable output shapes
- agents, which define model calls and dependencies
- output, which defines the final JSON object returned by the workflow

```txt
provider ollama {
    driver: "ollama"
    models: ["qwen3.5:32b"]
}

agent greeting {
    model: ollama("qwen3.5:32b")
    prompt: "Write a short welcome message."
    output: string
}

output {
    greeting: agent.greeting
}
```

## What the stack does today

Engine AI has three useful layers:

1. **Parser**: converts workflow text into a typed AST.
2. **Validator**: checks names, schema references, dependency cycles, secret leaks, and reference paths.
3. **Runtime**: executes validated workflows with the default OpenAI and Ollama provider factory.

<Info>
  The parser and validator currently understand more DSL surface area than the
  default runtime executes. Pages that document `for` loops, `context(...)`,
  `compact(...)`, `template(...)`, and `tool.*` references call out the current
  runtime status explicitly.
</Info>

## Why this DSL is useful

- **Readable**: workflows stay close to the business problem.
- **Typed**: schemas, arrays, tuples, unions, and enums are first-class.
- **Composable**: agent references form a dependency graph automatically.
- **Safe**: validation blocks leaked secrets and invalid reference paths early.
- **Embeddable**: the Rust API supports parse-only, validate-only, and execution flows.

## A more complete example

```txt
provider openai {
    driver: "openai"
    models: ["gpt-4.1-mini"]
}

input {
    product_name: string
    audience: string
}

agent release_summary {
    model: openai("gpt-4.1-mini")
    prompt: "Summarize {{ input.product_name }} for {{ input.audience }}."
    output: {
        summary: string
        key_points: [string; 3]
    }
}

output {
    product_name: input.product_name
    summary: agent.release_summary.summary
    key_points: agent.release_summary.key_points
}
```
