Superwire is a declarative DSL for building AI agent workflows. A workflow is a plain text `.wire` file that describes:

- which model providers are available
- what input and secrets the caller must pass
- which agents run and what each one returns
- which tools, resources, and prompts can be imported from MCP servers
- what final JSON object the caller receives

The usual runtime path is the **Superwire executor service**. You run the Docker image, send a base64-encoded workflow to `/execute`, and receive JSON. For streaming UX, send the same payload to `/execute/stream` and consume Server-Sent Events.

```bash
docker run --rm -p 8080:8080 rmilewski/superwire-executor
```

<Info>
  The examples below assume the executor is available at <code>http://localhost:8080</code>. Change the host or port to match your deployment.
</Info>

## A minimal workflow

Save this as `task_summary.wire`:

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

input {
    project_id: number
    task_id: number
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

agent summarize_task {
    model: ai("flash")
    instruction: "Write a concise summary for task {{ input.task_id }} in project {{ input.project_id }}."
    output: {
        summary: string
        next_action: string
    }
}

output {
    project_id: input.project_id
    task_id: input.task_id
    summary: agent.summarize_task.summary
    next_action: agent.summarize_task.next_action
}
```

Then execute it:

```bash
WORKFLOW_SOURCE_BASE64=$(base64 -w0 task_summary.wire)

curl -s http://localhost:8080/execute \
  -H 'Content-Type: application/json' \
  -d @- <<JSON
{
  "input": {
    "project_id": 14,
    "task_id": 109
  },
  "secrets": {
    "endpoint": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "mcp_summarizer_endpoint": "http://localhost:8000/mcp/summarizer",
    "api_key": "YOUR_API_KEY",
    "models": {
      "flash": "qwen3.6-plus",
      "pro": "qwen3.6-plus",
      "max": "qwen3.6-plus"
    }
  },
  "workflow_source_base64": "$WORKFLOW_SOURCE_BASE64"
}
JSON
```

The response is the final workflow output as JSON:

```json
{
  "project_id": 14,
  "task_id": 109,
  "summary": "...",
  "next_action": "..."
}
```

## Mental model

Superwire runs as a dependency graph. If an agent references `input.project_id`, that value must be present in the request. If an agent references `agent.other_agent.summary`, Superwire runs `other_agent` before the dependent agent. Independent agents can run concurrently.

## Important syntax choices

- Use `instruction:` for the text sent to the model.
- Use `uses:` to give an agent access to tools.
- Agent `output:` is always an object-shaped block.
- Put credentials in `secrets`, not in `input` or inline strings.
- Use `schema` blocks for reusable structured data.
- Use `dynamic` blocks when a value must be produced by a tool call before agents run.
