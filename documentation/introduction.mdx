## What is Engine AI?

Engine AI is a domain-specific language (DSL) designed for building sophisticated AI agent workflows. It provides a declarative syntax for orchestrating multiple AI models, managing dependencies between agents, and producing structured outputs.

## Key Features

### 🎯 Declarative Workflow Definition

Define complex AI workflows using a clean, readable syntax. No boilerplate code - just describe what you want to accomplish.

```ai
// Define a simple summarization agent
agent summary {
    model <- "ollama/qwen3:8b"
    output <- { text: string }
    prompt <- "Summarize the following text: {{ input.text }}"
}
```

### 🔗 Dependency Management

Agents can depend on outputs from other agents, creating sophisticated execution graphs that Engine AI automatically resolves.

```ai
agent analyze {
    model <- "ollama/qwen3:8b"
    prompt <- "Analyze this summary: {{ summary.text }}"
}
```

### 📊 Type-Safe Schemas

Define structured outputs with full JSON Schema validation, ensuring your AI agents produce reliable, predictable data.

```ai
schema person {
    name: string
    age: number
    email: string
    hobbies: [string]
}
```

### ⚡ Parallel Processing

Use `for_each` to process collections in parallel, dramatically reducing execution time for batch operations.

```ai
agent process_items for_each item in input.items {
    model <- "ollama/qwen3:8b"
    prompt <- "Process: {{ item }}"
}
```

### 🧠 Context Sharing

Share conversation history between agents for coherent multi-turn interactions.

```ai
agent first {
    model <- "ollama/qwen3:8b"
    context <- shared_context
    prompt <- "Start the conversation"
}

agent second {
    model <- "ollama/qwen3:8b"
    context <- shared_context
    prompt <- "Continue based on previous response"
}
```

## Language Bindings

Engine AI provides native bindings for multiple programming languages:

<Tabs>
  <Tab title="Rust">
    ```rust
    use engine_ai::Engine;

    let engine = Engine::new();
    let result = engine.execute_workflow("workflow.ai").await?;
    ```
  </Tab>
  <Tab title="JavaScript/TypeScript">
    ```typescript
    import { Engine } from 'engine-ai';

    const engine = new Engine();
    const result = await engine.executeWorkflow('workflow.ai');
    ```
  </Tab>
  <Tab title="CLI">
    ```bash
    engine-ai run workflow.ai
    ```
  </Tab>
</Tabs>
