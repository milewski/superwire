---
title: Parallel Processing
description: Author a looped agent over an input array and see the intended result shape.
---

This example is based on `crates/core/workflows/agent_for_loop.ai`.

```ai-dsl
provider openai {
    driver: "openai"
    endpoint: "https://api.openai.com/v1"
    api_key: "test-api-key"
    models: ["gpt-4.1-mini"]
}

input {
    numbers: [number]
}

agent input_number_note for n in input.numbers {
    model: openai("gpt-4.1-mini")
    prompt: "Write a short note for input number {{ n }}"
    output: {
        number: number
        note: string
    }
}

output {
    input_numbers: agent.input_number_note
}
```

Intended output shape:

```json
{
  "input_numbers": [
    { "number": 1, "note": "..." },
    { "number": 2, "note": "..." }
  ]
}
```

Looped agents execute in the current runtime and return an array value at `agent.<looped_agent_name>`.
