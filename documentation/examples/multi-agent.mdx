---
title: Multi-Agent Pipeline
description: Build a small dependency chain where one agent summarizes and another reviews the result.
---

```ai
provider openai {
    driver: "openai"
    endpoint: secrets.openai_endpoint
    api_key: secrets.openai_api_key
    models: [secrets.openai_model]
}

secrets {
    openai_endpoint: string
    openai_api_key: string
    openai_model: string
}

input {
    interview_notes: [string]
}

agent summarize_notes {
    model: openai(secrets.openai_model)
    prompt: "Summarize these interview notes into three findings: {{ input.interview_notes }}"
    output: {
        findings: [string; 3]
        summary: string
    }
}

agent review_findings {
    model: openai(secrets.openai_model)
    prompt: "Review this summary and call out the biggest research risk: {{ agent.summarize_notes.summary }}"
    output: {
        biggest_risk: string
        follow_up_questions: [string]
    }
}

output {
    findings: agent.summarize_notes.findings
    summary: agent.summarize_notes.summary
    biggest_risk: agent.review_findings.biggest_risk
    follow_up_questions: agent.review_findings.follow_up_questions
}
```

## What it demonstrates

- `input.*` references in the first agent
- `agent.*` references in the second agent
- automatic dependency ordering
- structured output validation on both agents
- secrets for provider configuration
