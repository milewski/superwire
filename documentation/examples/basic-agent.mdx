---
title: Basic Agent
description: "The smallest useful workflow shape: provider, agent, and output."
---

This example mirrors `crates/executor/tests/fixtures/001_minimum.wire`.

```wire
provider openai from openai {
endpoint: "http://localhost:1234/v1"
    api_key: "test-api-key"
}

model openai_model from openai {
    id: "model-a"
}

agent greeting {
    model: model.openai_model
    instruction: "Write a short welcome message."
    output: string
}

output {
    greeting: agent.greeting
}
```

## Why it is useful

- it shows the minimum valid provider-to-agent-to-output path
- it demonstrates the `model:` provider call syntax (positional argument)
- it demonstrates the `instruction:` property (not `prompt:`)
- it keeps the public workflow result explicit through the `output` block

## Expected output shape

```json
{
  "greeting": "Hello and welcome..."
}
```
