---
title: Basic Agent
description: A minimal workflow with one input, one agent, and one output.
---

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

input {
    name: string
}

agent greeting {
    model: ai("flash")
    instruction: "Greet {{ input.name }} in one friendly sentence."
    output: {
        message: string
    }
}

output {
    message: agent.greeting.message
}
```

This is the smallest useful shape: declare runtime secrets, declare typed input, configure a provider, run one agent, and expose a final JSON output.
