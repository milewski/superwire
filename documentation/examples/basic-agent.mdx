---
title: Basic Agent
description: "The smallest useful workflow shape: provider, agent, and output."
---

This example mirrors `crates/core/workflows/minimum.ai`.

```ai
provider openai {
    driver: "openai"
    endpoint: secrets.openai_endpoint
    api_key: secrets.openai_api_key
    models: [secrets.openai_model]
}

secrets {
    openai_endpoint: string
    openai_api_key: string
    openai_model: string
}

input {
    name: string
}

agent greeting {
    model: openai(secrets.openai_model)
    prompt: "Write a short welcome message for {{ input.name }}."
    output: string
}

output {
    greeting: agent.greeting
}
```

## Why it is useful

- it shows the minimum valid provider-to-agent-to-output path
- it demonstrates the current `model:` provider call syntax
- it uses secrets for configuration to keep credentials separate from workflow code
- it keeps the public workflow result explicit through the `output` block

## Expected output shape

```json
{
  "greeting": "Hello and welcome..."
}
```
