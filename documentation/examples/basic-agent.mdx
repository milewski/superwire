## Simple Greeting Agent

The most basic workflow contains a single agent that generates text:

```ai hello.ai
// Configure the LLM provider
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

// Define a terminal agent (marked with <-)
<- agent greeting {
    model <- "ollama/qwen3:8b"
    prompt <- "Say hello and introduce yourself as an AI assistant"
}
```

### Running the Workflow

```bash
engine-ai run hello.ai
```

### Expected Output

```json
{
    "greeting": {
        "text": "Hello! I'm an AI assistant powered by Engine AI..."
    }
}
```

<Info>
  The `<-` prefix marks this as a terminal agent, so its output is included in the workflow result.
</Info>

## Agent with Input

Add input parameters to make your workflow dynamic:

```ai personalized_greeting.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

// Define input schema
input {
    name: string
    language: string
}

// Use input in the prompt with {{ }}
<- agent greeting {
    model <- "ollama/qwen3:8b"
    prompt <- """
        Greet {{ input.name }} in {{ input.language }}.
        Be friendly and welcoming.
    """
}
```

### Running with Input

```bash
engine-ai run personalized_greeting.ai --input '{"name": "Alice", "language": "Spanish"}'
```

### Expected Output

```json
{
    "greeting": {
        "text": "¡Hola Alice! Bienvenida..."
    }
}
```

## Agent with Structured Output

Define a schema to get structured, validated data:

```ai person_generator.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

<- agent person {
    model <- "ollama/qwen3:8b"
    
    // Define output schema
    output <- {
        name: string
        age: number
        occupation: string
        hobbies: [string]
        email: string
    }
    
    prompt <- """
        Generate a random person with:
        - name (full name)
        - age (between 20-60)
        - occupation
        - hobbies (array of 3 hobbies)
        - email address
        
        Return as JSON.
    """
}
```

### Running the Workflow

```bash
engine-ai run person_generator.ai
```

### Expected Output

```json
{
    "person": {
        "name": "Sarah Johnson",
        "age": 32,
        "occupation": "Software Engineer",
        "hobbies": ["hiking", "photography", "cooking"],
        "email": "sarah.johnson@example.com"
    }
}
```

<Tip>
  Access specific fields: `person.name`, `person.age`, `person.hobbies`
</Tip>

## Classification Agent

Use enums to constrain outputs to specific values:

```ai sentiment_classifier.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

input {
    text: string
}

<- agent classify {
    model <- "ollama/qwen3:8b"
    
    output <- {
        sentiment: "positive" | "negative" | "neutral"
        confidence: number
        keywords: [string]
    }
    
    prompt <- """
        Classify the sentiment of this text: {{ input.text }}
        
        Return:
        - sentiment: must be exactly "positive", "negative", or "neutral"
        - confidence: 0.0 to 1.0
        - keywords: array of key words/phrases
    """
}
```

### Running the Workflow

```bash
engine-ai run sentiment_classifier.ai --input '{"text": "I love this product! It works great."}'
```

### Expected Output

```json
{
    "classify": {
        "sentiment": "positive",
        "confidence": 0.95,
        "keywords": ["love", "great", "works"]
    }
}
```

## Data Extraction Agent

Extract structured information from unstructured text:

```ai extract_contact.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

input {
    text: string
}

<- agent extract {
    model <- "ollama/qwen3:8b"
    
    output <- {
        name: string | null
        email: string | null
        phone: string | null
        company: string | null
        address: {
            street: string | null
            city: string | null
            country: string | null
        }
    }
    
    prompt <- """
        Extract contact information from this text: {{ input.text }}
        
        Find:
        - name
        - email
        - phone number
        - company name
        - address (street, city, country)
        
        Use null for missing fields.
        Return as JSON.
    """
}
```

### Running the Workflow

```bash
engine-ai run extract_contact.ai --input '{
    "text": "Contact John Smith at john@example.com or call 555-1234. He works at Acme Corp in New York."
}'
```

### Expected Output

```json
{
    "extract": {
        "name": "John Smith",
        "email": "john@example.com",
        "phone": "555-1234",
        "company": "Acme Corp",
        "address": {
            "street": null,
            "city": "New York",
            "country": null
        }
    }
}
```

## Content Generation Agent

Generate rich content with metadata:

```ai blog_post.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

input {
    topic: string
    target_audience: string
}

<- agent generate {
    model <- "ollama/qwen3:8b"
    
    output <- {
        title: string
        slug: string
        excerpt: string
        content: string
        word_count: number
        reading_time: number
        tags: [string]
        seo: {
            meta_title: string
            meta_description: string
            keywords: [string]
        }
    }
    
    prompt <- """
        Write a blog post about {{ input.topic }} for {{ input.target_audience }}.
        
        Include:
        - Catchy title
        - URL-friendly slug
        - Brief excerpt (2-3 sentences)
        - Full content (300-500 words)
        - Word count
        - Estimated reading time (minutes)
        - 5 relevant tags
        - SEO metadata (title, description, keywords)
        
        Return as JSON.
    """
}
```

### Running the Workflow

```bash
engine-ai run blog_post.ai --input '{
    "topic": "AI agents",
    "target_audience": "developers"
}'
```

### Expected Output

```json
{
    "generate": {
        "title": "Building AI Agents: A Developer's Guide",
        "slug": "building-ai-agents-developers-guide",
        "excerpt": "AI agents are transforming how we build software...",
        "content": "Full article content here...",
        "word_count": 450,
        "reading_time": 3,
        "tags": ["AI", "agents", "development", "automation", "LLM"],
        "seo": {
            "meta_title": "Building AI Agents: A Developer's Guide | Your Site",
            "meta_description": "Learn how to build AI agents...",
            "keywords": ["AI agents", "LLM", "automation"]
        }
    }
}
```

## Quiz Generator Agent

Generate educational content:

```ai quiz_generator.ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

input {
    topic: string
    difficulty: "easy" | "medium" | "hard"
    num_questions: number
}

<- agent generate_quiz {
    model <- "ollama/qwen3:8b"
    
    output <- {
        title: string
        description: string
        questions: [{
            question: string
            options: [string]
            correct_answer: number
            explanation: string
        }]
    }
    
    prompt <- """
        Generate a {{ input.difficulty }} quiz about {{ input.topic }}.
        Create {{ input.num_questions }} multiple choice questions.
        
        For each question:
        - question: the question text
        - options: array of 4 possible answers
        - correct_answer: index (0-3) of correct option
        - explanation: why the answer is correct
        
        Return as JSON.
    """
}
```

### Running the Workflow

```bash
engine-ai run quiz_generator.ai --input '{
    "topic": "JavaScript",
    "difficulty": "medium",
    "num_questions": 3
}'
```
