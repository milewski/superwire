---
title: Structured Output
description: Use schemas, enums, arrays, and nested objects to keep agent output predictable.
---

```txt
provider openai {
    driver: "openai"
    models: ["gpt-4.1-mini"]
}

schema ReleaseSummary {
    title: string "Short release title"
    status: "draft" | "ready" | "published" "Release state"
    key_points: [string; 3] "Exactly three key points"
    metadata: {
        confidence: number
        audience: string
    } "Nested metadata"
}

input {
    release_notes: [string]
    audience: string
}

agent summarize_release {
    model: openai("gpt-4.1-mini")
    prompt: "Summarize these release notes for {{ input.audience }}: {{ input.release_notes }}"
    output: schema.ReleaseSummary
}

output {
    result: agent.summarize_release
    status: agent.summarize_release.status
    confidence: agent.summarize_release.metadata.confidence
}
```

## What it demonstrates

- named schema reuse through `schema.ReleaseSummary`
- string enums inside output types
- fixed-length arrays
- nested object access in the final output
