## Using Schemas

Define schemas for structured output:

```ai
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

schema UserProfile {
    name: string
    age: integer
    email: string
    interests: array
}

<- agent extractor {
    model <- "ollama/qwen3:8b"
    schema <- UserProfile
    prompt <- "Extract user profile from: John Doe, 30 years old, john@example.com, likes hiking and photography"
}
```

## Nested Structures

Create complex nested schemas:

```ai
schema Address {
    street: string
    city: string
    country: string
    postal_code: string
}

schema Company {
    name: string
    address: Address
    employees: integer
    founded: integer
}

<- agent company_extractor {
    model <- "ollama/qwen3:8b"
    schema <- Company
    prompt <- "Extract company info from text"
}
```

## Array Outputs

Generate arrays of structured data:

```ai
schema Product {
    name: string
    price: float
    category: string
    in_stock: boolean
}

<- agent product_list {
    model <- "ollama/qwen3:8b"
    schema <- [Product]
    prompt <- "Extract all products from this catalog"
}
```

## Accessing Structured Data

Use structured output in subsequent agents:

```ai
schema Analysis {
    sentiment: string
    confidence: float
    topics: array
}

<- agent analyzer {
    model <- "ollama/qwen3:8b"
    schema <- Analysis
    prompt <- "Analyze this text"
}

agent reporter {
    model <- "ollama/qwen3:8b"
    prompt <- "Create report: Sentiment is {{ analyzer.sentiment }} with {{ analyzer.confidence }} confidence. Topics: {{ analyzer.topics }}"
}
```

## Best Practices

</Tip>
