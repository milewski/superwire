---
title: Structured Output
description: Use schemas, enums, arrays, and nested objects to keep agent output predictable.
---

```wire
provider openai {
    driver: "openai"
    endpoint: "https://api.openai.com/v1"
    api_key: "test-api-key"
    models: ["gpt-4.1-mini"]
}

schema release_summary {
    /// Short release title
    title: string

    /// Release state
    status: enum {
        draft
        ready
        published
    }

    /// Exactly three key points
    key_points: [string; 3]

    /// Nested metadata
    metadata: {
        confidence: number
        audience: string
    }
}

input {
    release_notes: [string]
    audience: string
}

agent summarize_release {
    model: openai("gpt-4.1-mini")
    instruction: "Summarize these release notes for {{ input.audience }}: {{ input.release_notes }}"
    output: schema.release_summary
}

output {
    result: agent.summarize_release
    status: agent.summarize_release.status
    confidence: agent.summarize_release.metadata.confidence
}
```

## What it demonstrates

- Named schema reuse through `schema.release_summary`
- Enums inside output types (`enum { draft, ready, published }`)
- Fixed-length arrays (`[string; 3]`)
- Nested object access in the final output (`agent.summarize_release.metadata.confidence`)
- Field descriptions using doc comments
