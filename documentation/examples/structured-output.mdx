---
title: Structured Output
description: Return machine-readable fields from an agent.
---

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

input {
    request: string
}

schema classification {
    category: enum { bug, feature, question }
    confidence: number
    reason: string
}

agent classify {
    model: ai("flash")
    instruction: "Classify this request: {{ input.request }}."
    output: schema.classification
}

output {
    category: agent.classify.category
    confidence: agent.classify.confidence
    reason: agent.classify.reason
}
```

Use structured outputs when callers need to route, filter, store, or validate the result.
