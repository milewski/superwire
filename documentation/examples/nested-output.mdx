---
title: Nested Output
description: Build nested JSON responses from agent outputs and literals.
---

```wire
secrets {
    endpoint: string
    api_key: string
    models: {
        flash: string
        pro: string
        max: string
    }
}

provider ai {
    driver: "openai"
    endpoint: secrets.endpoint
    api_key: secrets.api_key
    models: {
        flash: secrets.models.flash
        pro: secrets.models.pro
        max: secrets.models.max
    }
}

input {
    project_id: number
    task_id: number
}

agent analyze {
    model: ai("flash")
    instruction: "Analyze task {{ input.task_id }}."
    output: {
        title: string
        summary: string
        labels: [string]
        score: number
    }
}

output {
    project: {
        id: input.project_id
    }
    task: {
        id: input.task_id
        title: agent.analyze.title
        summary: agent.analyze.summary
    }
    metadata: {
        labels: agent.analyze.labels
        score: agent.analyze.score
        generated_by: "superwire"
    }
}
```

The final output block can shape the public response independently from internal agent output shapes.
