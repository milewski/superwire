## Nested output object

```wire
provider openai {
    driver: "openai"
    endpoint: "http://localhost:1234/v1"
    api_key: "test-api-key"
    models: ["model-a"]
}

agent summary {
    model: openai("model-a")
    instruction: "Write a project status summary with a confidence score."
    output: {
        text: string
        confidence: float
    }
}

output {
    version: 2
    generated_by: "status_workflow"
    report: {
        source: "workflow"
        overview: { text: agent.summary.text }
        metrics: {
            confidence: agent.summary.confidence
            status: "ok"
        }
    }
}
```

## What it demonstrates

- **Agent references with field access**: `agent.summary.text` and `agent.summary.confidence`
- **Hardcoded values in output**: `version: 2`, `generated_by: "status_workflow"`, `status: "ok"`
- **Nested objects in output**: `report.overview` and `report.metrics`
- **Mixed types**: `float` from agent output alongside `number` literals and `string` literals
- **No input or secrets required**: this workflow is fully self-contained

The output would look like:

```json
{
  "version": 2,
  "generated_by": "status_workflow",
  "report": {
    "source": "workflow",
    "overview": { "text": "The project is on track..." },
    "metrics": {
      "confidence": 0.87,
      "status": "ok"
    }
  }
}
```

## Literal values in output

The `output` block supports all literal expression types:

```wire
output {
    hardcoded_string: "fixed-value"
    hardcoded_number: 42
    hardcoded_boolean: true
    hardcoded_null: null
    agent_value: agent.assistant
}
```

This is useful for metadata, versioning, or any static fields alongside dynamic agent results.
