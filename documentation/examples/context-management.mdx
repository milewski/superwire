## Building Context

Accumulate context through agent chain:

```rust
provider ollama {
    driver <- "ollama"
    config <- { endpoint <- "http://localhost:11434" }
    models <- ["qwen3:8b"]
}

<- agent research {
    model <- "ollama/qwen3:8b"
    prompt <- "Research the topic"
}

<- agent outline {
    model <- "ollama/qwen3:8b"
    prompt <- "Create outline based on: {{ research.text }}"
}

<- agent draft {
    model <- "ollama/qwen3:8b"
    prompt <- "Write draft using outline: {{ outline.text }} and research: {{ research.text }}"
}

<- agent refine {
    model <- "ollama/qwen3:8b"
    prompt <- "Refine draft: {{ draft.text }}"
}
```

## Shared Configuration

Use shared config across agents:

```rust
config <- {
    style <- "professional"
    tone <- "friendly"
    max_length <- 500
}

agent writer1 {
    model <- "ollama/qwen3:8b"
    prompt <- "Write in {{ config.style }} style, {{ config.tone }} tone, max {{ config.max_length }} words"
}

agent writer2 {
    model <- "ollama/qwen3:8b"
    prompt <- "Write in {{ config.style }} style, {{ config.tone }} tone, max {{ config.max_length }} words"
}
```

## Context Filtering

Select relevant context:

```rust
<- agent analyzer {
    model <- "ollama/qwen3:8b"
    prompt <- "Analyze and extract key points"
}

agent summarizer {
    model <- "ollama/qwen3:8b"
    prompt <- "Summarize only the key points: {{ analyzer.text }}"
}
```

## Best Practices

<Tip>
  Keep context focused and relevant to avoid overwhelming agents.
</Tip>

<Info>
  Use variables to share configuration and reduce duplication.
</Info>
