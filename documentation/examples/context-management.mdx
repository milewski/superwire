---
title: Context Management
description: Express full-context and compacted-context flows in the current DSL.
---

```wire
provider openai from openai {
endpoint: "https://api.openai.com/v1"
    api_key: "test-api-key"
}

model openai_model from openai {
    id: "gpt-4.1-mini"
}

input {
    product_name: string
    customer_feedback: [string]
}

agent research_analysis {
    model: model.openai_model
    instruction: "Analyze this customer feedback for {{ input.product_name }}: {{ input.customer_feedback }}"
    output: {
        themes: [string]
        risks: [string]
        opportunities: [string]
    }
}

agent summary_from_full_context {
    model: model.openai_model
    context: context(agent.research_analysis)
    instruction: "Write a short executive summary from the available context."
    output: string
}

agent summary_from_custom_compact_context {
    model: model.openai_model
    context: compact(
        agent: agent.research_analysis,
        model: model.openai_model,
        inference: {
            temperature: 0.1
            max_tokens: 1_500
        },
        instruction: "Keep only the highest-signal themes and risks."
    )
    instruction: "Write a short executive summary from the customized compacted context."
    output: {
        summary: string
        top_actions: [string; 3]
    }
}
```

## What it demonstrates

- `context(agent.x)` passes the full output of an agent as context
- `compact(...)` with named arguments configures a custom compaction step
- Nested object output types with multiple fields
- Field references in the output block (`agent.summary_from_custom_compact_context.summary`)

<Info>
  <code>context(...)</code> and <code>compact(...)</code> execute at runtime when used
  in an agent <code>context:</code> property. See the
  <a href="/advanced/context-sharing">Context and Compaction</a> page for details.
</Info>
